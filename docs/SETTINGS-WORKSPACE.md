# 工作区外观与工具设置

工作区级外观、首页排序和视图保存在私有 `ui-preferences-v1.json`，与项目级面板布局分开。写入使用 revision CAS 和原 requestId 精确重试；记录最近打开时间只在项目成功打开后写入，不改变外观 revision。读取首页摘要不会初始化时间线。

外观支持深色、浅色与跟随系统。浅色已按用户确认的第三版启用；跟随系统会实时响应系统外观变化。草稿可即时预览，放弃后恢复已保存选择；保存仍使用工作区偏好的版本与请求ID保护。

保存成功后，其他窗口会按版本提示重读偏好；有未保存草稿或结果未明请求的窗口会延后同步，避免覆盖草稿或改变原有冲突基线。回到窗口时也会进行只读刷新。原生窗口背景跟随已保存选择，跟随系统使用操作系统实际外观。

视频和图片连接在“设置 → 生成服务”管理，替代原“模型与服务”和“扩展”中的图片入口。六家内置视频服务各一份，自定义视频可以多份；官方 OpenAI 图片、本机 ComfyUI 各一份，自定义图片最多十份。页面复用 Mio 的三段式外壳，各家详情保持挂载，切中栏保留草稿与密码，底部统一保存。跨文件部分成功会如实显示，不自动重发未知保存。详细行为见 [GENERATION-SERVICES.md](GENERATION-SERVICES.md)。

每家服务独立保存密钥，同一公司的视频、图片和 Mio 不共享。自定义图片使用页面创建草稿时生成的小写 UUID；保存后保持选中身份，删除后只留 UUID 墓碑，不能复用。其密钥只绑定服务身份、profile 和规范化完整地址，换模型保留密钥但使旧配置修订的审核失效；改地址并选择“保留”会保存成功并断开这一家的旧密钥。密码只在各自输入框 DOM 中保留，不进入 React state；提交前同步清空全部输入，隐藏整页、放弃或获准关闭时也清空。取消关闭不清，暂存删除只清本家。

视频、自定义图片设置采用 v2；官方图片、ComfyUI 和 `liveGeneration` 格式不变。严格有效的旧视频 v1、自定义图片 v1 读为空 v2，页面提示“旧版生成服务设置已重置，请重新配置。” 读取不写盘、不导入或解密旧密钥，首次明确保存才写新格式；坏文件、未知版本、权限不安全和链接替换均拒绝。保存结果不明时只读核对，不自动重放密钥。界面不再提供历史密钥恢复；“仅本次运行”提示：“应用退出后，正在进行的生成没法继续查询结果。”

网页生成面板通过项目地址下的图片服务接口明确选择 UUID，再准备和确认该服务的审核。旧 CLI/MCP/Mio 无 ID 入口仅在恰有一家自定义图片服务时精确解析；多家时提示“有多个自定义图片服务，请在生成面板里选择。”，不按模型或启用状态猜选。显式 CLI/MCP/Mio 服务选择放在 0.1.x，现有工具目录不增加这些网页操作。相关请求与示例见 [IMAGE-COMPATIBLE.md](IMAGE-COMPATIBLE.md)。

`GET /api/workspace-info` 返回当前版本、渠道、数据目录、受限文件大小估计和工具路径；不返回访问令牌、模型密钥或连接配置。统计最多检查 20000 个目录项，跳过符号链接，遇到边界或读取失败时明确标记估计不完整。

`POST /api/media-tools/check` 只接受空对象，检测服务启动时确定的 FFmpeg / ffprobe 版本及 libx264、AAC、drawtext、subtitles。请求不能指定命令、参数或可执行路径。

桌面设置通过固定的 `mioon:workspace-tools` 桥复用首次启动的路径校验。浏览和保存只接受工具路径，保存前验证工具身份与必需编码器，原生当前主文档在异步校验后仍须有效。保存后重启应用生效；显式启动环境路径继续遵循原有优先级。浏览器展示服务配置并支持检测，不提供任意程序执行入口。

“打开所在位置”在桌面端只打开当前工作区目录，不接受调用方路径。浏览器展示可复制的规范路径；每个项目使用独立 `.mioon` 文件，本机历史、缓存与托管素材按项目隔离。

项目永久删除的准入、受控事务和中断恢复见 [PROJECT-LIFECYCLE.md](PROJECT-LIFECYCLE.md)。Mio授权见 [AGENT-AUTHORIZATION.md](AGENT-AUTHORIZATION.md)。
