# Mioon 0.3.1

## 打开旧项目时先确认升级

用 Mioon 0.3.1 打开旧格式项目时，应用会提示升级。选择「升级并打开」后，Mioon 会先保存并校验一份原格式备份，再转换项目。项目格式升级是单向的，重要项目请先自行备份。想先查看，可以选择「以只读方式打开」。

## 下载

从 [v0.3.1 发布页](https://github.com/starroyhq/mioon/releases/tag/v0.3.1)下载 `mioon-0.3.1-mac.dmg`。Apple 芯片和 Intel Mac 使用同一个安装包。正式安装包使用 Developer ID 签名，并须通过 Apple 公证。安装步骤见[安装与首次运行指南](../INSTALL.zh-CN.md)。

## 生成镜头

- 生成失败时，画板属性栏、剪辑里的生成面板和任务中心都会显示具体原因，例如账户余额不足、密钥无效、没有模型使用权限、找不到模型、请求太频繁或服务商暂时故障。只有可以重新提交的失败才显示「重试」。
- 查询已提交的任务时，如果服务商暂时无法返回结果，任务会保持「生成中」。Mioon 会继续查询原任务，查询不会再次提交生成或产生第二笔生成费用。
- 只有一个可用的视频服务时会自动选中它。可用服务有多个时，默认选这个镜头上次使用且仍可用的服务。没有可沿用的服务时，可以自己选择。
- 提交生成后，任务中心不再自动打开。在画板属性栏或剪辑生成面板就能查看进度或点「取消」。
- 费用确认框更简洁，新增「取消」按钮。点「取消」即可退出确认，尚未提交任务。

## 剪辑

- 拖动片段遇到冲突时，提示会写出与哪段重叠，多段冲突时还会显示数量。相关片段会在时间线上标出来。
- 格式 5 项目可以正常用 ⌘Z、⇧⌘Z 或「编辑」菜单撤销和重做。
- 预演属性栏去掉了两段操作说明。

## 项目首页

- 升级旧项目时，如果暂时无法确认结果，可以关掉升级对话框，继续在首页新建或打开其他项目。
- 重启电脑后再打开从访达复制的旧项目，Mioon 仍会先识别出副本。选择「作为新项目打开」后，再进入升级流程。
- 关闭首页窗口时，确认按钮改为「仍然关闭」。

## 外部 Agent

Claude Code、Codex 等外部 Agent 现在可以通过源码里的命令行或 MCP 编辑格式 5 项目的画板和时间线。查看、预览、提交、撤销和重做都使用统一的 `sequence` 操作。替换片段来源时，如果所选版本来自其他镜头且未被当前镜头采纳，会明确显示拒绝原因。生成前的确认规则沿用上一版。见[外部 Agent 安装与连接指南](../EXTERNAL-AGENTS.zh-CN.md)和[格式 5 命令](../CLI.md#格式-5统一序列动作外部-agent)。

安装包自带的命令行和设置里的一键技能安装计划随 0.4.0 提供。

## 更新方法

0.2.0 及以上版本会在应用内提示更新，也可以从发布页下载 DMG 手动安装。0.1.x 及更早版本需要手动下载安装。

需升级项目格式时，先查看[备份与升级说明](#打开旧项目时先确认升级)。

上一版的功能和项目格式说明见 [v0.3.0 发布说明](v0.3.0.zh-CN.md)。
