# Mioon 0.1.0

**内置视频 Agent 的本地创作工作台。** 用画板整理故事，在时间线上剪辑，让 Mio 在你的授权范围内协助处理镜头、字幕和生成。导入、剪辑、预览和导出已有素材，不需要 AI 账号或密钥。

## 下载

从 [v0.1.0 发布页](https://github.com/starroyhq/mioon/releases/tag/v0.1.0)选择安装包。

| 电脑 | 安装包 |
| --- | --- |
| macOS · Apple 芯片 | `mioon-0.1.0-mac-arm64.dmg` |
| macOS · Intel | `mioon-0.1.0-mac-x64.dmg` |

- 两个安装包都有 Developer ID 签名，并经过 Apple 公证。打开 DMG，把 Mioon 拖进「应用程序」，不需要 Node.js 或 pnpm。
- 0.1.0 只发布 macOS 桌面版。安装包在 macOS 15 上构建，较旧的系统没有逐一验证。
- `Source code` 附件是源码，不是安装包。

## 首次启动：视频工具

应用不附带 `ffmpeg` 和 `ffprobe` 命令行工具。首次需要配置视频工具时，可以选择：

- **「下载并安装」** Mioon 构建的 FFmpeg 7.1.5。应用会校验下载内容，只在你选择后开始下载。这些工具按 GPL-2.0-or-later 分发，源码和许可见[视频工具发布页](https://github.com/starroyhq/mioon/releases/tag/media-tools-7.1.5-1)。
- **「选择已安装的工具」** 可使用自己的 `ffmpeg` 和 `ffprobe`。工具必须支持 `libx264` 和 AAC 编码，字幕、颜色和响度等功能还需要对应的滤镜。

具体步骤见[安装与首次运行指南](https://github.com/starroyhq/mioon/blob/main/docs/INSTALL.zh-CN.md)。

## 这一版可以做什么

- **单文件项目**：作品保存在 `.mioon` 文件里，媒体文件单独存放。可以在访达双击项目文件，或从首页打开最近项目。点首页「从示例开始」，选择保存位置后打开示例的独立副本。
- **项目管理**：在首页项目菜单中选「复制项目…」或「移到废纸篓…」。项目位于只读卷或网络共享时，可从打开提示选择「复制到…」。素材移位后可重新指向。项目菜单提供「存为版本…」和「版本历史…」，在版本历史中也可以查看自动备份。
- **画板和时间线**：整理图片、文字和镜头，编排视频、图片、声音和字幕，调整片段与音量，预览后导出 MP4（H.264 + AAC）。新项目可选横屏、竖屏或方形 1080 画幅。导出失败或取消后，可点「重新导出」从头开始。
- **Mio**：每家服务单独保存连接，你从中选用一个模型。可以查看执行步骤、确认付费操作、核对并撤销仍可撤销的修改，也能查看本轮用量。协议由你明确选择（Chat Completions、Responses 或 Anthropic Messages），失败时不会自动切换协议。OpenAI 默认使用 `gpt-6.1-terra` 和 Responses。通过项目菜单「项目规范…」查看或编辑 `AGENTS.md`，确认启用后让 Mio 读取。
- **生成服务**：按需配置视频、图片、自定义兼容连接或 ComfyUI。真实生成默认关闭，启用后仍须遵守授权和确认。新生成的版本不会自动替换时间线上已经固定使用的素材。
- **后台工作**：应用仍在运行时，关闭项目窗口不会取消后台任务。项目暂时打不开时，需要写回的工作会暂停，等项目可用后继续。
- **界面**：深色、浅色或跟随系统，支持简体中文、繁体中文、英语和日语。

## 已知限制

- **没有离线收件箱**：项目不在时，需要写回的任务会暂停，结果不会另存一份完整媒体。服务商保留结果的时间有限，请尽快接回磁盘或找回项目。关闭窗口、停止等待或退出应用，不保证服务商会取消请求或退款。
- **分享时要带上素材**：`.mioon` 不是包含全部媒体的压缩包。Mio 对话、任务、版本历史和草稿是这台电脑上的本机记录，不会随文件带走。版本和自动备份也不能找回被删除的媒体。
- **没有「另存为」**：请使用「复制项目…」或打开受限位置时的「复制到…」。
- **项目文件没有永久删除入口**：移到系统废纸篓会保留素材和本机记录。项目还开着、还有会写回的工作，或 Mio 还有没结束的轮次时，不能移走。项目文件找不到时，可以从「设置 › 工作区 › 本机记录」查看是否有可清理的记录。
- **云盘识别有限**：只识别 iCloud 云盘和系统 `CloudStorage` 目录下的同步盘。项目文件不能直接在网络共享上打开。
- **没有自动更新**：更新前先正常退出，保管好 `.mioon`、素材和需要的本机记录，再下载新版安装。
- **AI 功能会联网、可能计费**：文本模型、连接检查、图片和视频生成可能把内容发给服务商并产生费用。部分服务和模型已实测，具体可用性取决于服务、模型和账户权限。
