# Mioon v0.1.0

**与 AI 共同创作的视频工作台**

从构思、镜头到剪辑，和 Mio 一起把想法做成作品。v0.1.0 是面向个人创作者的桌面试用版：工作台承载可编辑的项目，Mio 在你的授权下参与规划与执行，创意和关键决定由你掌握

## 可以做什么

- 用画板整理参考素材、文字、镜头和版本，在同一个项目中切换到时间线
- 编排图片、视频与声音，添加手动字幕，调整片段和音量，合成预览并导出 MP4；新项目支持横屏、竖屏与方形 1080 画幅
- 让 Mio 读取已授权的项目内容，调用已有工具推进镜头整理和剪辑；你可以查看变化、接着修改，并处理确认、冲突或未知结果
- 按需连接视频、图片生成服务及 Mio 模型；生成新版本保留，时间线中的固定来源不会自动替换
- 使用独立项目窗口、系统托盘与原生菜单；提供深色、浅色、跟随系统主题和简体中文、繁体中文、英语、日语

导入、剪辑、预览和导出已有素材不需要 AI 账号或密钥

## 下载与开始

| 平台 | 安装附件 |
| --- | --- |
| macOS · Apple Silicon | `mioon-0.1.0-mac-arm64.dmg` |
| macOS · Intel | `mioon-0.1.0-mac-x64.dmg` |

**本版先发布 macOS，Linux 与 Windows 桌面包暂不提供**。发布流水线使用 macOS 15，不代表所有系统版本均已验证。正式安装附件以本页 Assets 实际提供的文件为准，`Source code` 不是桌面安装包

首次使用请看[安装与首次运行指南](https://github.com/starroyhq/mioon/blob/v0.1.0/docs/INSTALL.zh-CN.md)。安装包已带应用所需的 Electron 运行环境，无需 Node.js 或 pnpm，但仍需在本机自行安装并选择 **FFmpeg 和 ffprobe**；它们没有随包提供，也不会自动下载。建议使用 7.1.5 或更新、带字幕及颜色等所需能力的完整构建，具体要求见指南

## 使用边界

- **先从短片和不重要的素材开始**。当前适合个人轻量创作，项目与素材默认在本机；没有自动云同步，请保留备份
- **没有自动更新**。后续版本需从发布页重新下载，升级前先备份并正常退出应用
- **AI 需要自行配置，可能计费**。外部模型和生成服务可能收到已授权的项目内容或媒体；连接测试也可能发出请求。停止等待不保证供应商取消请求或退款，结果未知时应先核对原任务
- **支持连接不等于全部实测**。已有[真实文本模型与本地模拟视频协作记录](https://github.com/starroyhq/mioon/blob/v0.1.0/docs/verification/ai-workflows-acceptance/DESKTOP-REAL-ACCEPTANCE.md)，其固定环境、模型和工具范围不代表所有供应商的真实付费图像或视频生成均已验收；模拟画面和导入的演示素材也不是这类验收证据
- **各项验证分别看待**。源码 CI、签名包检查与原生冒烟的结果以本版本确切提交的 [Actions 记录](https://github.com/starroyhq/mioon/actions/workflows/release-desktop.yml)为准；历史检查不能代替本次最终包验收
