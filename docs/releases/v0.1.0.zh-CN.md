# Mioon v0.1.0

**内置视频 Agent 的本地创作工作台。**用画板整理故事，在时间线上剪辑，让 Mio 在授权范围内协助完成镜头、字幕和生成。导入、剪辑、预览和导出已有素材不需要 AI 账号或密钥。

这是 0.1.0 的发布前说明，按 2026-11-05 已合入的代码核对。标有“**待合入后核对**”的功能仍需检查最终界面；下载附件及签名包验收状态以实际发布记录为准。

## 这一版可以做什么

- **本地项目文件**：作品保存在 `.mioon` 中，媒体单独保存；最近项目提供搜索、排序和列表/网格。Mio、版本历史、后台任务和草稿属于这台电脑的本机记录，不在 `.mioon` 里。
- **画板和时间线**：整理图片、文字和镜头，编排视频、图片、声音与手动字幕，调整片段与音量，合成预览并导出 MP4。新项目可选横屏、竖屏或方形 1080 画幅。
- **Mio**：每家服务独立保存连接，从中选用一个模型；查看执行步骤、确认付费操作、核对变化并撤销仍可撤销的修改。支持明确选择 Chat Completions、Responses 或 Anthropic Messages 协议，不自动切换协议重试。
- **生成服务**：按需配置视频、图片、自定义兼容连接或 ComfyUI；首次配置默认不启用真实生成，启用后仍须遵守授权和确认。新生成版本不自动替换时间线上固定使用的来源。
- **后台工作**：应用仍运行时，关掉项目窗口不等于取消任务；项目不可用时，需要写回的工作暂停，首页显示等待项目的提示。
- **本机版本和自动备份**：已提供版本保存、预览、恢复及项目文件自动备份能力；**版本历史和备份的界面待合入后核对**。它们都不备份媒体。
- **复制和回收**：复制项目/复制到…携带版本，不携带 Mio 对话、任务、撤销或草稿；普通复制仍引用原媒体。移到废纸篓只移走 `.mioon`，保留素材和本机记录。**相关菜单、示例入口、素材重新指向待合入后核对**。

界面提供深色、浅色、跟随系统主题，以及简体中文、繁体中文、英语和日语。独立项目窗口、系统托盘和原生菜单的具体用法见[使用指南](https://github.com/starroyhq/mioon/blob/v0.1.0/docs/USER-GUIDE.zh-CN.md)。

## 安装与首次启动

从 [v0.1.0 发布页](https://github.com/starroyhq/mioon/releases/tag/v0.1.0)选择安装附件：

| 电脑 | 安装附件 |
| --- | --- |
| macOS · Apple Silicon | `mioon-0.1.0-mac-arm64.dmg` |
| macOS · Intel | `mioon-0.1.0-mac-x64.dmg` |

**0.1.0 的桌面发行范围为 macOS；Windows、Linux 桌面版不在本次范围。**安装附件以 Assets 实际公开的文件为准，`Source code` 不是安装包；尚无附件时表示发布仍在准备中。发布流水线使用 macOS 15，不代表所有旧系统均已验证。

将 Mioon 拖到“应用程序”后打开，无需安装 Node.js 或 pnpm。**FFmpeg 和 ffprobe 不随应用附带**：首次提示配置视频工具时，可明确选择“下载并安装”Mioon 构建的 **7.1.5**，也可选择自己安装的两个可执行文件。

Mioon 提供的工具按 GPL-2.0-or-later 分发，对应源码、构建材料和许可随[视频工具发布](https://github.com/starroyhq/mioon/releases/tag/media-tools-7.1.5-1)提供。应用会校验下载；不会未经选择自动下载。自备 FFmpeg 必须有 `libx264` 和 AAC 编码器，否则不能完成启动配置；字幕、颜色和响度等功能还需要相应滤镜。步骤见[首次启动与 FFmpeg](https://github.com/starroyhq/mioon/blob/v0.1.0/docs/USER-GUIDE.zh-CN.md#首次启动配置视频工具)和[安装指南](https://github.com/starroyhq/mioon/blob/v0.1.0/docs/INSTALL.zh-CN.md)。

先用不重要的素材完成一段短片，确认预览、声音和导出，再连接付费服务。

## 已知限制

- **最终签名包仍待验收**：本稿尚无本候选最终 macOS 签名包的完整验收结果，不能将源码 CI 或组件测试视为整包已验。签名、公证、确切架构与系统、原生检查结果以本次[发布 Actions](https://github.com/starroyhq/mioon/actions/workflows/release-desktop.yml)及最终验收记录为准；发布前需补核。
- **没有离线收件箱**：项目不在时，需要写回的任务暂停，不另存完整媒体结果。服务商保留结果的时间有限，及时接回磁盘、找回项目并核对原任务；关闭窗口、停止等待或退出应用不保证服务商取消请求或退款。
- **云盘识别有限**：只识别 iCloud 云盘与 `~/Library/CloudStorage/` 下的同步盘；iCloud“桌面与文稿”同步和旧式同步目录可能识别不出。没有提示不等于安全的本机位置。项目文件不能直接在网络共享上打开；外置盘和 exFAT 的提示及限制见指南。
- **分享需要带上素材**：`.mioon` 不是包含所有媒体的压缩包。本机记录不自动同步到另一台电脑；版本和自动备份不能恢复被删除的媒体。项目打包留在 **0.1.x**。
- **没有永久删除**：只提供移到系统废纸篓，素材和本机记录保留。项目窗口未关、仍有会写回的工作或还有未结束的 Mio 轮次（含暂停、等待确认和中断待处理）时拒绝移走。
- **0.1.0 用复制项目代替另存为**：另存为尚不可用，入口继续隐藏；复制也需等桌面入口就绪后使用。不能用旧项目包流程代替。
- **尚待合入的界面**：项目文件的完整打开/恢复/重新指向流程、示例与复制/废纸篓菜单、版本/备份、`AGENTS.md` 项目规范、本轮用量和“设置 › 工作区 › 本机记录”均标为**待合入后核对**；当前不据设计稿宣称这些入口已经可用。
- **没有自动更新或自动云同步**：更新前先保管 `.mioon`、素材及需要的本机记录，正常退出，再下载新版。外部同步软件不提供 Mioon 的协作语义。
- **AI 支持范围不等于全部真实验收**：文本模型调用、连接检查、图片和视频生成可能发送内容并计费。已有[真实文本模型与本地模拟视频记录](https://github.com/starroyhq/mioon/blob/v0.1.0/docs/verification/ai-workflows-acceptance/DESKTOP-REAL-ACCEPTANCE.md)只证明其固定环境与操作；不代表所有供应商、模型或付费图像/视频组合已验证。
