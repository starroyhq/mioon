# Mioon 0.3.0

## 打开旧项目时先确认升级

第一次用 Mioon 0.3.0 打开 0.2 版及更早版本创建的项目时，应用会提示升级项目。选择「升级并打开」后，Mioon 会先在本机记录中自动保存一份原格式备份，再转换项目；备份保存或校验失败时不会继续。升级后，0.2 版及更早版本无法再打开这个项目。

如果暂时不想升级，可以选择「以只读方式打开」，查看镜头、画板卡片和时间线摘要。项目文件保持原格式，不会被改写。

如果在访达里复制了旧版项目并打开副本，应用会先确认这是一份副本；选择「作为新项目打开」后再进入升级，原项目不会被改动。

升级完成后，画板缩略图、成片条时长以及与剪辑同步的预览和导出都按项目当前内容显示。

## 下载

从 [v0.3.0 发布页](https://github.com/starroyhq/mioon/releases/tag/v0.3.0)下载 `mioon-0.3.0-mac.dmg`。Apple 芯片和 Intel Mac 使用同一个安装包。正式安装包使用 Developer ID 签名，并须通过 Apple 公证。安装步骤见[安装与首次运行指南](../INSTALL.zh-CN.md)。

## 画板与剪辑连在一起

- 画板上的实线表示成片顺序，从成片卡开始依次经过镜头。没有连进成片的镜头会标为「游离 · 不在成片里」。
- 画板和剪辑主轨双向同步：在画板上连接或断开镜头，主轨会同步增加或移除对应片段；在主轨上挪动、裁剪或删除片段，画板上的成片顺序和长度也会更新。一次改动算一步，可以撤销。
- 底部成片条显示镜头数和总时长，长度按主轨实际裁剪后的片段计算，和剪辑里的时间一致。
- 镜头台词会进入剪辑字幕；修改台词或字幕，另一边会同步更新。
- 画板可以放素材和文字，从素材库添加或拖入图片、视频、音频和文字，也可以复制、粘贴、删除并从「已删除」恢复。删除已经生成过视频或已经用在主轨上的镜头前会先确认；复原的镜头接回成片末尾，主轨上的片段长度按可用素材计算。
- 画板工具条的「预演」点一次会新建一张预演卡，并自动选中、显示它的属性。属性栏可以打开预演，编辑后保存、关闭、重开仍在。
- 做过画板操作后，素材卡仍会显示实际使用次数；确实无法计算时不再用一句长说明盖住缩略图。
- 从素材、主体或预演拖到镜头的参考口，可以建立生成参考。连线会标明首帧、构图、主体、参考音频或参考视频；当前服务不支持这条参考时，会直接在界面上标出。
- 画板连线失败时会说明具体原因，例如预演还没有画面、素材还没有准备好、节点已删除或首尾帧顺序不对；有画面的预演可以正常连接。
- 从素材库添加视频片段、把片段复制到轨道，以及在轨道空白处粘贴，都在剪辑里完成，并可撤销。
- 剪辑可以新增画面或音频轨，给轨道改名、静音、隐藏和调整顺序；主轨始终保持固定身份，音频轨不能隐藏，轨道最多 12 条。

## 在剪辑里生成镜头

- 在主轨片段上点右键，可以选择「在前面生成镜头」或「在后面生成镜头」。
- 在主轨末尾的空白处点右键，可以「在末尾生成镜头」；在其他画面轨的空白处、且位置落在主轨镜头范围内时，可以「在这里生成镜头」。
- 选好入口后，应用先在时间线上放一个还没生成的占位镜头并打开生成面板，这一步不会提交生成任务。叠加轨的「在这里生成镜头」也一样，生成结果会填回这一段。
- 生成面板会显示镜头描述、生成输入、时长和服务。选好服务后点「生成」：真实服务会先弹出费用确认，确认后才提交；本机模拟服务直接开始。生成按项目画幅提交。
- 选中任意还没生成的占位镜头，都会显示同一个生成面板；生成完成后再显示普通属性。
- 生成服务下拉只列出已经配置好并且当前可用的服务。同一家服务有内置服务和多个连接时，会用连接名区分；没有可用服务时，可以点「去设置生成服务」打开生成服务设置。
- 生成中显示进度和「取消生成」；失败时显示按错误原因翻译的说明和「重试」；结果未知时不出重试，提示到任务中心核对原任务。
- 支持声音的生成模型会根据镜头台词一并生成声音；画板属性栏和剪辑生成面板使用同一套生成状态。

## 主体

- 画板上的人物、道具、场景和风格可以放成主体卡，卡片从主体库选择，不复制主体的原始作品。
- 把主体卡连到镜头后，默认跟随该主体的最新版；也可以在镜头右侧锁定某个版本、断开或恢复连接。
- 生成时，支持主体参考的模型会把对应版本作为参考；不支持的会标明原因。预演里给人偶或道具指定的主体也会进入生成输入。

## 片段声音

视频片段自带的声音可以分离到音频轨、静音，或另存为音频素材。属性栏可以测量已保存片段的响度，并按对白响度匹配增益。匹配后保存不会一直停在草稿状态；主轨上还有没生成的占位镜头时，单个片段也照样能测量响度。

## 导出

导出分为「检查、设置、确认、导出、完成」五步。检查会核对编码能力和要用的素材；设置可以选择画质、编码参数和保存位置；确认后再开始导出。导出中可以查看进度、取消，或转到后台继续，完成后可以打开成片。

导出前可以先生成样片检查一段画面和声音；剪辑预览区也可以更新合成预览。较长的时间线会分几段并行编码，导出更快。

如果上一次导出没有拿到明确结果，打开导出时应用会先核对一次，可以选择「继续上次的导出」或放弃，不会悄悄再发一条相同的导出。导出进行中关掉对话框再打开，仍会看到当前进度；已经完成的导出不会占住下一次导出，重新导出会从第 1 步开始。

导出对话框只保留当前步骤需要的信息和状态，去掉了多余的说明性小字；导出记录和剪辑属性里的说明也更精简。使用较新版本 FFmpeg 时，带透明度的图片和叠加层不再变暗；升级上来的旧项目也能正常预览和导出。

## 项目文件

如果打开项目时发现项目文件和这台电脑上的记录不是同一份内容，应用会先请你选择：

- **用这个文件继续**：这个文件里的内容继续使用；旧对话、Mio 记录和撤销记录会归档，不再执行，版本会留下。如果有结果未知的生成任务，会单独提醒。
- **从版本恢复…**：从可恢复的版本中选择一个，比较后再恢复。恢复前会先保存现在的内容，旧对话、Mio 记录和撤销记录同样会归档。

从首页、访达、「打开…」或启动恢复打开项目时，只要发现文件和本机记录对不上，都会先进入这个选择。

复制项目会建立独立项目，并按复制入口带上或留空本机版本历史，不会和原项目串用记录。移到废纸篓仍只移动 `.mioon` 文件，素材和本机记录保留；找不到项目文件时，可以从「设置 › 工作区」的本机记录中清理。

## Mio

- Mio 可以在剪辑里调整片段、加字幕，也能整理画板、主体和轨道；它的修改和你的修改共用撤销记录，可以单独撤销，也不会覆盖你正在编辑的地方。
- 让 Mio 生成镜头前，会先显示服务、模型、时长、参考素材和可能产生的费用，等你确认后再提交。付费生成默认需要确认。
- 提交结果不明确时，应用会保留原请求供核对，不会自动重复执行。Mio 的回复支持标题、列表和代码块，长代码块可以横向滚动。

## 其他改进

- 播放时的时间码和播放头更稳定，长时间剪辑时不容易出现保存状态跳动。
- 连接密钥只保存在系统安全存储中；系统安全存储不可用时会说明原因并提供重试，不再回退到进程内保存。
- Google 视频连接更新为 Gemini Omni；已有连接会保留，已受理的 Veo 任务仍按原协议查询和下载。
- 导出和预览中的透明图片叠加颜色已修正，使用新版 FFmpeg 时不会再变暗。
- ⌘Q、菜单栏托盘和程序坞的退出都会走同一套流程。还有没做完的导出、生成、预览、导入或未确认结果时，会先列出工作并问一次；页面长时间没响应时，应用会再问一次，不会卡在退不出去的提示上。
- macOS 窗口左上角的窗口按钮与页面顶栏控件对齐。
- Windows 开发版的窗口标题栏已重做，但本版仍只提供 macOS 桌面安装包，Windows 还不是正式支持的平台。

## 更新方法

0.2.0 会在应用内提示更新到 0.3.0，也可以从发布页下载 DMG 手动安装；0.1.x 及更早版本需要手动下载安装。第一次用 0.3.0 打开旧项目时会提示升级项目格式；升级是单向的，应用会先自动备份原格式，重要项目请先自行备份。

上一版更新见 [v0.2.0 发布说明](v0.2.0.zh-CN.md)。平台、基础功能和已知限制见 [v0.1.0 发布说明](v0.1.0.zh-CN.md)。
