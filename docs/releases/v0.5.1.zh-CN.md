# Mioon 0.5.1

## 修复

- 修复项目放在 exFAT 或 FAT32 格式的外置盘上时，复制导入素材、保存生成的视频和图片、新建内置示例项目会失败的问题。现在也可以把项目复制到这两种格式的盘上。这些写入问题从 0.1.0 起就存在，已在 0.5.0 发布说明的「已知问题」里列出。
- 恢复失败的操作时，Mioon 会清理能确认是自己先前写入的文件，保留来源无法确认的文件。

## 下载

从 [v0.5.1 发布页](https://github.com/starroyhq/mioon/releases/tag/v0.5.1)下载 `mioon-0.5.1-mac.dmg`。Apple 芯片和 Intel Mac 使用同一个安装包。正式安装包使用 Developer ID 签名，并须通过 Apple 公证。安装步骤见[安装与首次运行指南](../INSTALL.zh-CN.md)。

## 打开旧项目时先确认升级

如果 Mioon 提示项目需要升级，可以选择「升级并打开」。Mioon 会先保存并校验一份原格式备份，再转换项目。项目格式升级是单向的，重要项目请先自行备份。想先查看，可以选择「以只读方式打开」。

## 更新方法

0.2.0 及以上版本会在应用内提示更新，也可以从发布页下载 DMG 手动安装。0.1.x 及更早版本需要手动下载安装。

需升级项目格式时，先查看[备份与升级说明](#打开旧项目时先确认升级)。

上一版的改进见 [v0.5.0 发布说明](v0.5.0.zh-CN.md)。
