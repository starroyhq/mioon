# Mioon 0.1.2

这一版更新了 Mio 的长任务和跟随体验，也改进了桌面版的项目首页与打开流程。

## 下载

从 [v0.1.2 发布页](https://github.com/starroyhq/mioon/releases/tag/v0.1.2)选择安装包。

| 电脑 | 安装包 |
| --- | --- |
| macOS · Apple 芯片 | `mioon-0.1.2-mac-arm64.dmg` |
| macOS · Intel | `mioon-0.1.2-mac-x64.dmg` |

正式安装包使用 Developer ID 签名，并须通过 Apple 公证。安装步骤见[安装与首次运行指南](../INSTALL.zh-CN.md)。

## Mio

- **长任务**移除了每轮 30 步的限制。同一操作反复失败、连续多次没有进展，或触及安全保护时，Mio 会暂停并说明原因。你可以直接继续，也可以补充说明后再继续。
- **跟随 Mio**默认开启。Mio 修改镜头、节点、片段或字幕后，会在画布或时间线上标出位置，并提示正在做什么。你可以点定位查看另一工作区的修改，也可以在 Mio 面板关闭跟随。
- **真实视频生成关闭时**，在提交前被拒绝的请求会提示「这次请求未提交」。需要开启时，可前往「设置 › 生成服务 › 常规」。
- **失败提示**更具体。读取模型列表或测试连接时，会说明能确认的密钥、权限、额度、网络等问题。Mio 的失败步骤也会在有详情时显示具体原因和可复制的诊断码。

## 画布与桌面版

- **画布点阵**在浅色和深色主题下都更清晰。
- **项目首页**在独立的入口窗口中打开，窗口会记住大小和位置。可以搜索项目、切换列表和网格，也可以从侧栏进入示例和帮助。
- **打开项目**时，最近项目和文件选择的发起界面会保留到项目可以显示。打不开时在原处提示，等得久了可以取消。可恢复的损坏项目会显示恢复界面，有可用的本机备份时可以恢复为新项目。
- **取消退出**后，项目首页会恢复可用。
- **视频工具路径**会保留你选中的 FFmpeg 和 ffprobe 路径，包括符号链接。在设置里保存路径后，可以直接点「重启本地服务」使它生效。
- **新生成的素材和新导出的视频**采用系统的普通文件权限。
- **新素材和示例项目的显示名称**会使用发起操作时的界面语言。已有内容保留原名。

## 更新方法

本版需要手动更新。先正常退出 Mioon，再下载适合你电脑的安装包，把 Mioon 拖进「应用程序」并替换旧版。更新前请备份重要的项目文件和素材。

基本功能、已知限制和各份指南见 [0.1.0 发布说明](v0.1.0.zh-CN.md)。
