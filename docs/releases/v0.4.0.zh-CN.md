# Mioon 0.4.0

## 打开旧项目时先确认升级

用 Mioon 0.4.0 打开旧格式项目时，应用会提示升级。选择「升级并打开」后，Mioon 会先保存并校验一份原格式备份，再转换项目。项目格式升级是单向的，重要项目请先自行备份。想先查看，可以选择「以只读方式打开」。

## 下载

从 [v0.4.0 发布页](https://github.com/starroyhq/mioon/releases/tag/v0.4.0)下载 `mioon-0.4.0-mac.dmg`。Apple 芯片和 Intel Mac 使用同一个安装包。正式安装包使用 Developer ID 签名，并须通过 Apple 公证。安装步骤见[安装与首次运行指南](../INSTALL.zh-CN.md)。

## 外部 Agent

- macOS 安装包自带命令行工具，无需另装 Node.js。打开「设置 → 外部 Agent」，可以一键安装命令行工具，以及 Claude Code 或 Codex 的技能。也可以复制对应的 MCP 接入命令，在终端执行。
- 命令默认安装到 `~/.local/bin`，shell 配置由你自行管理。
- 保持 Mioon 运行，Agent 就能读取和修改你打开的项目，包括格式 5 项目的画板和时间线。提交付费生成前，Agent 仍应先向你确认。

[外部 Agent 安装与连接指南](../EXTERNAL-AGENTS.zh-CN.md)

## 剪辑和界面

- 去掉了界面里「工作台」等旧叫法。
- 在剪辑里拖动片段时，停在可能冲突的位置，时间线会提前标出会重叠的片段。
- 导出的视频文件改用导出名（没填就用项目名），同名时自动加序号，不覆盖已有文件。

## 更新方法

0.2.0 及以上版本会在应用内提示更新，也可以从发布页下载 DMG 手动安装。0.1.x 及更早版本需要手动下载安装。

需升级项目格式时，先查看[备份与升级说明](#打开旧项目时先确认升级)。

上一版的改进见 [v0.3.1 发布说明](v0.3.1.zh-CN.md)。
