# Mioon 0.1.1

修复版本。修正 OpenAI 推理模型在 Mio 多步任务中途反复失败的问题。建议使用 OpenAI 的用户更新。

## 下载

从 [v0.1.1 发布页](https://github.com/starroyhq/mioon/releases/tag/v0.1.1)选择安装包。

| 电脑 | 安装包 |
| --- | --- |
| macOS · Apple 芯片 | `mioon-0.1.1-mac-arm64.dmg` |
| macOS · Intel | `mioon-0.1.1-mac-x64.dmg` |

两个安装包都有 Developer ID 签名，经过 Apple 公证，在 macOS 15 上构建。

## 修复

- **Mio 使用 OpenAI（Responses 协议）时，某一步反复失败：** 如果模型在这一步做了推理，会显示「模型返回的内容不完整或不受支持，请检查协议与模型设置」，点「重试这一步」也一样失败。原因是 OpenAI 在同一次回复里会把推理内容加密两次，两份密文不同，0.1.0 把这种情况误判成格式错误。0.1.1 会分别校验两份推理内容，其他内容仍要求完全一致。

## 更新方法

本版没有自动更新。先正常退出 Mioon，再下载新安装包，把 Mioon 拖进「应用程序」并替换旧版。项目文件、素材和本机记录都不受影响，可以直接用 0.1.1 打开。

0.1.0 里因为这个问题失败的那一轮不会自动继续。更新后，可以在那一轮点「重试这一步」，也可以开一个新对话重新发送。

功能介绍、已知限制和各份指南见 [0.1.0 发布说明](v0.1.0.zh-CN.md)。
