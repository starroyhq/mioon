# Mioon 0.2.0

## 打开旧项目时先确认升级

第一次用 Mioon 0.2.0 打开 0.1 版创建的项目时，应用会提示升级到项目格式 4。选择「升级并打开」后，Mioon 会先在本机记录中自动保存一份原格式备份。升级后，0.1 版 Mioon 无法再打开这个项目。

如果暂时不想升级，可在提示中选择「以只读方式打开」，查看镜头、画板卡片和时间线摘要。项目文件会保留原格式。

## 下载

从 [v0.2.0 发布页](https://github.com/starroyhq/mioon/releases/tag/v0.2.0)下载 `mioon-0.2.0-mac.dmg`。Apple 芯片和 Intel Mac 使用同一个安装包。

正式安装包使用 Developer ID 签名，并须通过 Apple 公证。安装步骤见[安装与首次运行指南](../INSTALL.zh-CN.md)。

## 画板

- 在画板空白处拖出选框，或按住 ⇧ 点击多选。拖动其中一张卡片，可以把选中的元素一起移动。
- 右键菜单可用于整理、复制和删除等操作。点「整理」或按 ⇧⌘L，镜头会按顺序排列，每行最多 10 个。复制、粘贴和创建副本都在同一个项目的画板内进行，镜头的生成版本留在原镜头中。
- 编辑可以撤销或重做。删除的元素也能从「已删除」找回。删除已生成过视频或已用在时间线上的镜头时，Mioon 会先请你确认，生成的视频留在素材库，已剪好的时间线保留原样。

## 画面比例与生成

- 每个项目有一个画框，可以在剪辑预览区切换 9:16、16:9、1:1、4:3、3:4 和 21:9。素材会等比适应画框，保持原比例。首次导入图片或视频，或首次把图片或视频放上时间线后，如果 Mioon 识别到另一种受支持的素材比例，会在预览区提示是否更改画框。
- 导出页会显示当前比例，改比例后原来的导出仍保留。需要新比例的成片时，可以重新导出。
- 新生成的视频默认用项目画框的比例。选用的模型不支持当前比例时，Mioon 会列出可用比例，由你决定如何调整。

## Mio

可以请 Mio 整理画板、删除或恢复画板上的元素，也可以请它更改项目的画面比例。如果要删除已生成过视频或已用在时间线上的镜头，Mio 每次都会请你确认。这些操作都支持在 Mio 的任务记录中撤销，之后由你修改过的内容会保留。

## 项目列表

首页和启动器会在后台检查项目文件。项目多，或项目放在外置盘、iCloud 上时，仍可使用界面。尚未确认的项目会显示「正在检查」。

## 更新方法

从旧版升级到 0.2.0 需要手动下载安装包。先备份重要的项目文件和素材，正常退出 Mioon，再打开下载的 DMG，把 Mioon 拖进「应用程序」并替换旧版。

安装 0.2.0 后，可以在 Mioon 内检查和安装以后发布的更新。

基本功能、已知限制和各份指南见 [0.1.0 发布说明](v0.1.0.zh-CN.md)。
