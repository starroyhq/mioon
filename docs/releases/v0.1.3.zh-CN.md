# Mioon 0.1.3

这一版修复了视频任务卡在「生成中」的问题，打开设置也更快了。配置生成服务时，可以先用新密钥检查连接，再选择要添加的模型。

## 下载

从 [v0.1.3 发布页](https://github.com/starroyhq/mioon/releases/tag/v0.1.3)选择适合你的安装包。

| 电脑 | 安装包 |
| --- | --- |
| macOS · Apple 芯片 | `mioon-0.1.3-mac-arm64.dmg` |
| macOS · Intel | `mioon-0.1.3-mac-x64.dmg` |

正式安装包使用 Developer ID 签名，并须通过 Apple 公证。安装步骤见[安装与首次运行指南](../INSTALL.zh-CN.md)。

## 视频任务

- 修复了服务商已生成完毕，Mioon 却一直显示「生成中」的问题。如果 macOS 等待钥匙串授权，Mioon 会提示你允许访问。允许后，Mioon 会自动检查已提交的任务，无需重新生成。
- 原密钥无法读取时，可以在原来的视频服务连接里重新保存原账户的密钥，再点「重新检查原任务」。Mioon 只查询和下载已有结果，不会重新生成或再次扣费。如果密钥仍无法访问原任务，可以到原服务商后台获取结果。
- 确定尚未提交的任务会提示「这次还没提交，没有扣费」。你可以取消，也可以用当前设置重新生成。重新生成仍需确认费用。

## 设置与生成服务

- **打开设置更快了**，项目多、缓存大时尤其明显。如果设置仍打开得慢，可以在「帮助 › 导出诊断日志…」把设置耗时、应用版本和窗口运行状态保存到本地。日志不含密钥、文件路径或项目名称。
- **配置并启用生成服务后即可使用。** 正式版移除了「真实生成」开关和「本地模拟」入口。手动发起付费生成时仍会确认费用。没有可用服务时，Mioon 会引导你去设置。
- **获取模型后可以选择要添加的型号。** Mio 和支持模型列表的视频服务会打开勾选列表。官方图片服务会显示当前使用的固定型号，自定义图片服务可以选用一个型号。选定后记得保存设置。
- **新密钥可以先试再保存。** 支持的服务可用刚填入的密钥直接检查连接或获取模型。保存才会替换原密钥，放弃更改仍使用原密钥。Mio 的连接检查会在你确认后发送一条测试消息，可能计费。

## 更新方法

本版需要手动更新。先正常退出 Mioon，再下载适合你电脑的安装包，把 Mioon 拖进「应用程序」并替换旧版。更新前请备份重要的项目文件和素材。

基本功能、已知限制和各份指南见 [0.1.0 发布说明](v0.1.0.zh-CN.md)。
