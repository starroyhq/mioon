# Mioon 使用指南

用自己的图片、视频和音乐先做一段短片，再按需连接 Mio 或生成服务。导入、剪辑和导出已有素材不需要 AI 账号或密钥。

本文是 0.1.0 发布前的使用指南，按 2026-11-05 已合入的代码核对。标有“**待合入后核对**”的界面仍在交付中，不能当作当前已有的按钮；发布前会再次核对。下载和平台范围见[安装指南](INSTALL.zh-CN.md)与[发布说明](releases/v0.1.0.zh-CN.md)。

## 首次启动：配置视频工具

安装包带有应用运行环境，不需要 Node.js 或 pnpm。FFmpeg 和 ffprobe 是另外配置的视频工具，**不随 Mioon 安装包附带**。

第一次启动时，如果还没有可用的视频工具，会出现“配置视频工具”：

1. **下载 Mioon 提供的工具**：macOS 上点“下载并安装”，下载适合 Apple Silicon 或 Intel 的 FFmpeg 7.1.5 和配套 ffprobe。应用显示下载、校验和安装进度，通过检查后保存路径。只有明确选择才会下载；关闭进度窗口或取消会中止本次下载。失败后可以重试或改选自己的工具。
2. **选择自己安装的工具**：点“选择已安装的工具”，先选 `ffmpeg`，再选 `ffprobe` 的可执行文件。不要选文件夹、压缩包或安装器。Mac 文件选择框可用 **⌘⇧G** 粘贴完整路径。

所选文件必须能运行，FFmpeg 必须带有 **`libx264` 和 AAC 编码器**。提示缺少必要编码器时，需要换完整构建，或重新启动后改用 Mioon 提供的版本；不能跳过检查进入应用。

启动检查通过不代表所有字幕和滤镜能力齐全。“设置 › 视频工具”的“检测工具”显示版本及 `libx264`、AAC、`drawtext`、`subtitles` 四项状态。下表列出不同功能的需求，不是该页的完整检测结果：

| 要做的事 | 需要的能力 |
| --- | --- |
| 导出常见 MP4 | `libx264`、`aac` |
| 字幕、本地模拟画面 | `subtitles`、`drawtext` 及字体支持 |
| 颜色、响度处理 | `zscale`、`loudnorm`、`ebur128` |
| 图片与缩略图 | PNG、WebP 编解码 |

缺少能力时，先更换工具，再重试相应操作。设置中下载或切换 Mioon 提供的版本后，按提示“重启本地服务”；手动保存工具路径后，按提示重启应用。移动或删除工具也需要重新配置。

Mioon 提供的下载版构建号为 7.1.5-1，按 GPL-2.0-or-later 分发；对应源码、构建材料和许可见[视频工具发布页](https://github.com/starroyhq/mioon/releases/tag/media-tools-7.1.5-1)。自行安装时使用配套的 ffmpeg/ffprobe，版本和具体功能要求另见[安装指南](INSTALL.zh-CN.md#3-准备视频工具)。

## 新建、打开与最近项目

在首页点“新建项目”，填写名称和说明，选择竖屏、横屏或方形画幅。当前桌面入口在系统“影片”目录下的 `Mioon` 中创建项目。打开已有项目可以在 Finder 中双击 `.mioon`，或用系统“打开方式”选择 Mioon。

首页列出本机登记的项目，可以按名称搜索，按最近打开、修改时间或名称排序，并切换列表或网格。最近项目只是入口，文件仍保存在原位置；拔掉外置盘或移动文件后，卡片会显示找不到项目及上次位置。

**待合入后核对：**新建时选择位置、首页“打开项目文件…”、重新定位和相关帮助入口，需等界面入口就绪。当前不要把旧“导入项目包”当成打开 `.mioon` 的替代方法。

### 从示例开始

应用已准备离线示例及其素材，实例化会创建独立项目和独立素材，原示例不变，也不需要调用付费服务。

**待合入后核对：**首页“从示例开始”的入口、选择目标位置与完成后的打开流程。示例只能创建到新的文件夹，不能合并或覆盖已有目录。需要提前练习时，可参考仓库的[示例素材说明](../examples/README.md)。

## 先完成一段短片

1. **导入素材**：在素材库选择图片、视频或音频，也可从文件管理器拖入。先用几份不重要的素材，确认能正常预览。
2. **整理与剪辑**：把参考、文字和镜头放到画板构思；把要成片的素材加入剪辑区，调整顺序、长短和音量。画板上的摆放不等于时间线上的片段顺序。
3. **添加手动字幕**：填写文字和时间，保存后重新渲染预览。这里不提供自动转录的承诺。
4. **检查成片预览**：编辑之后更新合成预览，核对画面、声音和字幕；源素材预览不能代替合成结果。
5. **导出 MP4**：核对导出内容、范围和设置，完成检查后确认导出。任务完成后打开成片，实际播放一次。详细参数见[导出设置](EXPORT-SETTINGS.md)。

导出确认窗口关闭后，已接受的任务仍会继续。失败时先看任务详情，确认原任务状态再决定下一步。

## 项目文件、素材与本机记录

一个作品由 **`.mioon` 项目文件和它引用的素材**组成。建议把需要一起移动的文件放在同一个项目文件夹里。

| 内容 | 保存在哪里 | 分享 `.mioon` 时会怎样 |
| --- | --- | --- |
| 镜头、画板、时间线、素材引用等项目内容 | `.mioon` 文件 | 随文件携带 |
| 视频、图片、音频等媒体 | 项目旁边或你选择的其他位置 | 不嵌入 `.mioon`，需要另行携带 |
| 版本历史、Mio 对话与撤销、后台任务、草稿 | 这台电脑的本机记录 | 手工复制或发送 `.mioon` 不会携带 |
| `AGENTS.md` 项目规范 | `.mioon` 所在文件夹 | 是单独的文件，需另行携带；另一台电脑仍需确认信任 |

桌面选择本机文件导入时，项目引用原文件，不会替你再复制一份。通过网页上传的素材放入项目的“素材”文件夹；生成结果在“生成”，成片在“导出”。不要因为素材已出现在列表里，就删除原媒体。

应用内“复制项目”和“复制到…”可以专门携带本机版本，规则见下文；这不等于复制全部本机记录。自动备份也不包括媒体或 Mio 记录。

## 移动、分享和找回素材

移动前先让任务结束，正常关闭项目；需要在文件管理器里搬动项目时，先正常退出应用。把 `.mioon` 和需要的素材文件夹一起移动，保留相对目录结构。外部目录里的媒体也要单独安排，不能只发送 `.mioon` 就认为对方已经拿到素材。

在新位置打开 `.mioon` 后，检查画面和声音。找不到素材时，先接回外置盘、下载云端占位文件，或找回原文件。素材内容发生变化与单纯换位置不同，不能仅凭同名文件认作原素材。

**待合入后核对：**“重新指向素材”和项目外目录确认的界面。预定流程是选择实际文件，核对找到的素材及仍然缺失的项目后再应用；内容已变化时需要单独决定是否使用新文件。入口就绪前不要照旧工作区路径手工改数据库。

项目外素材的读取许可保存在本机，外来项目不会自动获得这些许可。确认一个目录不包含其子目录；需要读取其他目录时仍要明确确认。

### 外置盘与同步文件夹

- 项目文件可放在可写的本机磁盘或外置盘。使用 exFAT 等不能提供常规权限位的卷时会提示限制，确认后可继续，并非一律拒绝。
- **网络共享上不能直接打开或编辑项目文件。**先复制到本机或可用的外置盘；“复制到…”的选择界面仍待合入后核对。
- 应用能识别的云盘位置限于 iCloud 云盘，以及 `~/Library/CloudStorage/` 下的同步盘。iCloud“桌面与文稿”同步、老式同步文件夹可能识别不出；没有提示不代表不是云盘。
- 使用同步盘时先确保文件已下载到本机，避免在多台电脑上同时编辑同一项目。同步软件不是 Mioon 的协作或备份服务；检测到文件与本机记录不一致时，需要先处理恢复选择。

## 复制项目、复制到…与废纸篓

**以下操作已实现，桌面菜单和选择器待合入后核对。**入口完成前，不使用旧项目包的导入、导出或复制流程代替。

| 操作 | 适合什么情况 | 携带的内容 |
| --- | --- | --- |
| 复制项目 | 从本机已登记项目建立独立项目 | 当前内容和本机版本历史；不带 Mio 对话、任务、撤销、草稿或自动备份 |
| 复制到… | 从选择的关闭文件建立新项目，包括受限来源的副本 | 当前内容；本机存在该项目的版本历史就必须携带，即使发生分叉；历史读不了则整笔拒绝 |
| 作为新项目打开 | 手工复制的文件与已登记原件身份相同，需要分开使用 | 给选中的副本建立新身份，不改变原件；不带原件版本、Mio 或任务 |
| 从示例开始 | 用内置示例建立项目 | 新项目和独立素材；不带示例的本机记录 |

普通复制和“复制到…”**继续引用同一份媒体**，不会把所有素材再复制一份。它们创建新的项目身份，不覆盖已有目标；源项目必须关闭，不能仍有窗口或会写回的工作。从本机已有版本历史的源项目复制时，历史损坏或被占用会整笔拒绝，不会悄悄省略版本。

**0.1.0 用“复制项目”代替另存为。**另存为尚不可用，入口未开放。

### 移到废纸篓

此操作只把 **`.mioon` 文件移到系统废纸篓，确认成功后撤下本机登记**，素材和本机记录都保留，不做永久删除。项目在窗口里打开、仍有会写回的工作，或仍有未结束的 Mio 轮次（包括暂停、等待回答/确认及中断待处理）时，会拒绝操作；保存的草稿本身不阻止移到废纸篓。

需要恢复时，在系统废纸篓中放回项目文件，再用 Mioon 打开。若系统操作结果不明，登记保留，文件可能已移走；先检查原位置和废纸篓，不重复删除。**废纸篓菜单和确认流程待合入后核对。**

## 版本历史与自动备份

版本和备份都保存在这台电脑上，**不代替素材备份**。丢失或删除本机记录后，仅凭 `.mioon` 不能找回原来的对话、任务或版本。

### 版本历史与恢复

版本保存的是项目内容的状态，不复制媒体，也不保存 Mio 的执行过程。保存时机包括手动保存、Mio 每轮首次真正修改前、恢复项目版本前，以及每天首次正常打开项目。

手动版本永久保留；自动版本保留“最近 20 条”与“最近 7 个本地日历日每天最早一条”的并集，正在使用的版本另受保护。恢复前的版本在本次清理中保留，之后仍按自动版本策略轮转。它不是每次鼠标操作都保存一份。

恢复前需要先看变化预览。部分受保护的结果会标为保持当前；恢复不会强行覆盖这些内容，也不会重跑旧的生成任务。现存素材保留当前已经修复的位置；需要补回的旧素材仍须满足读取许可，恢复不能找回被删掉的媒体字节。

恢复成功会先保留恢复前版本。恢复改变了的目标可能不再满足旧 Mio 撤销的条件；没有变化的独立目标仍按原规则处理。项目有工作未完成时，先处理工作再恢复。

**待合入后核对：**“版本历史”、保存版本、变化预览与恢复确认界面。它与镜头的生成版本对比是两种功能，不能用后者代替项目恢复。

### 自动备份与恢复为新项目

正常打开和关闭项目时会尝试自动备份；内容没有变化时跳过，通常保留最近三份有效副本。备份只含项目文件，不含素材、版本、Mio 对话、任务或 `AGENTS.md`。失败会留下状态提示，不意味着素材也已安全备份。

从备份恢复会建立**新项目和新的本机记录**，不覆盖原件；素材仍指向原媒体。不要把备份文件改名后直接当普通项目打开，应走恢复入口。

**待合入后核对：**“自动备份”标签页、状态、只读查看及“恢复为新项目”界面。更详细的范围见[项目备份](PROJECT-BACKUPS.md)。

## Mio：连接、规范与用量

### 配置连接和选用模型

在“设置 › Mio”管理连接。每家服务单独保存接口、协议、密钥和候选模型；Mio 从中**选用一个模型**，不会同时把同一轮发给所有服务。模型服务可能计费，不使用 Mio 就无需配置。

“获取模型”和“检查”用于读取服务返回的模型列表，不发送项目内容；能够列出模型不表示该模型已经通过文本调用。保存并选用模型后，“设置 › Mio”的“测试连接”才会发送固定的文本测试；它也需要发送授权，可能产生用量。

协议由你明确选择，不会失败后自动切到另一种协议。首次向新地址和模型发送时，核对授权说明；撤销授权后，再次发送会重新询问。密钥不要写进对话、项目文件或截图。

Mio 的本地修改、不可撤销操作和付费生成有各自的执行方式。付费生成默认先确认；停止一轮会保留已完成的修改，也不保证服务商撤销已接受的请求。结果未知时先核对原任务，不重复提交。对话、提问、撤销和恢复操作见[Mio 使用说明](MIO-GUIDE.zh-CN.md)。

### 项目规范（AGENTS.md）

项目规范是与 `.mioon` 同目录的独立 `AGENTS.md`，用于长期记录风格、角色设定和约束。规范不能代替发送授权或付费确认；来自别处或已变化的文件需要核对并信任。

Mio 提议修改规范时必须单独展示差异，等你明确批准；“完全放行”也不能跳过这次批准。当前轮使用发送时固定的规范，修改从下一轮生效。规范不属于项目版本或自动备份，分享时需要另带文件。

**待合入后核对：**“项目规范”编辑入口、信任提示及修改确认卡。旧“项目说明”不是同一个功能，不能把内容和权限直接等同。

### 本轮用量

**待合入后核对：**每轮 Mio 的用量展示。它将显示服务返回的用量及无法完整统计的情况，只读，不显示费用；不要将 token 数当作最终账单，以服务商账单为准。

## 配置生成服务

视频、图片和 Mio 使用各自的连接设置。先在“设置 › 生成服务”配置需要的生成服务，再在镜头或图片生成界面选择模型、核对输入。

视频服务提供已支持的平台连接，也可添加自定义连接；自定义服务必须符合对应适配器的协议，不是任意网址都能使用。图片支持 OpenAI、自定义兼容服务和 ComfyUI；ComfyUI 需自行启动匹配的服务并选择 checkpoint，当前使用固定的文生图流程，不支持上传任意工作流。具体范围见[视频服务](PROVIDERS.md)、[图片生成](IMAGE-ACTIVATION.md)和[图片编辑](IMAGE-EDITING.md)。

“设置 › 生成服务”的**“真实生成”**开关控制外部生成提交，常规首次配置默认关闭，已有配置沿用保存值。启用前保存连接，核对发给谁、发送哪些素材及可能的费用。这个开关与 Mio 的模型调用授权、付费操作确认分别生效；关闭真实生成不代表 Mio 不会调用文本模型。

已生成的镜头版本会保留；新生成不会自动替换时间线上已经固定使用的版本。配置成功、模型列表可见或连接测试通过，都不代表该供应商的所有付费生成组合已实测。密钥选“仅本次运行”时，退出后可能失去继续查询任务所需的凭据，需要重新配置。

## 关闭窗口后的任务与找回项目

关闭项目窗口不等于取消已经接受的生成或导出；应用仍运行时，后台工作可以继续。**正常退出应用后，本机任务不会继续处理**；若退出时提示进程未确认结束，先按提示核实。服务商已接受的请求可能继续执行，下次启动需要核对状态。Mio 被中断的轮次不会自动继续或自动重发未知请求。

项目文件丢失、外置盘拔出、只读或被占用时，需要写回项目的任务会暂停。首页会列出等待项目的提示、数量和原因。先接回磁盘或找回原文件，再正常打开项目，让原任务核对并继续；重新定位按钮仍待合入后核对。不要为取回同一个结果新建一条生成任务。

0.1.0 **没有离线收件箱**，不会在项目不可用时另存一份完整媒体结果供以后无限期领取。服务商只保留结果一段时间，找回项目要及时；结果已经过期时可能无法继续下载。

## 清理找不到项目的本机记录

**待合入后核对：**“设置 › 工作区 › 本机记录”列表和清理确认。它用于删除找不到项目所遗留的本机记录，不是清空所有项目，也不删除媒体文件。

删除前确认不再需要该项目的版本、Mio 对话、任务和草稿。文件又找到了、项目正在打开，或还有生成任务没结束时，不能删除；先找回项目让任务结束，再处理记录。把项目移到废纸篓不会自动执行这项清理。

## 保管作品与反馈问题

重要作品另行备份 `.mioon`、素材和需要的 `AGENTS.md`；需要保留本机历史时，也要保管本机记录。Mioon 没有自动云同步、永久删除或项目打包交付；项目打包留在 0.1.x。

更新前先保留备份并正常退出，再下载新版安装包。当前没有自动更新。遇到错误，保留原文件和原任务，不删除数据库、锁文件或本机记录尝试“修复”。
