# 本地恢复：范围、容量与备份

基线：`c7850f6d0a11656015075f396de82469d30b3993`。本片只校正已有界面的说明，共用静态TSX组件；不增加保存字段、恢复权限、数据库迁移、状态机或清理功能。定向测试、类型检查、fresh Linux打包与有限原生验收已完成，父级独立类型检查与全量已通过。以下是既有实现的范围，不把它们计为本片新增能力。

## 四类本地记录不是同一个台账

- **片段属性草稿**：每个工作区累计最多128个项目/时间线/片段目标槽。保存的是当前片段属性输入、原revision及媒体来源。恢复只填表；明确业务保存仍走原时间线台账。
- **成片名称与固定导出意图**：每个工作区累计最多128个项目槽。草稿只含名称；明确导出前另外保存原请求编号和精确参数，限定 `timeline.render` 的 `purpose:'export'`。其输出规格来自当次确认的意图，不是对任意规格输入的自动草稿承诺。
- **镜头标题/提示词与固定文字保存意图**：每个工作区累计最多128个项目/镜头槽。只覆盖标题和提示词及该次 `shot.update` 的精确文字保存，不包括参考图、时长、画幅或其余生成设置。文字确认不会清除非文字待确认请求。
- **最近项目定位**：一个可覆盖的位置记录，与每项目已有视图偏好配合；它没有128槽上限，也不证明某次业务保存成功。

前三类各自独立计数，清除草稿后仍保留版本墓碑，占用的目标槽不会回收；同一已存在目标可以继续更新，达到上限会拒绝新增目标。该上限不是“磁盘空间已满”。尚未提供槽位清理或压缩按钮，请勿手工删旁文件或旧请求身份绕过限制。

任务中心另有既有SQLite本地编辑台账，按其固定操作目录保存，保留上限4096条。它与上述旁文件不同。成片导出与镜头文字意图在各自原面板中发现和处理，任务中心不能被理解为已经列出所有旁文件意图。其余画板/素材编辑、镜头非文字参数、渲染预览及既有仅会话路径仍按各自旧合同处理；不概括为所有提交都能跨应用重建恢复。

## 读取、恢复、执行分别确认

重新打开或读取记录不会自动业务保存、导出、批准Agent提案或提交模型。恢复草稿只修改对应表单；恢复原请求的按钮明确使用原编号与原参数，可能首次执行尚未提交的操作。未知响应和网络期限不等于取消，也不是未应用证明，不能换键盲目重交。

“放弃当前输入”不等于删除原草稿或取消在途写入。清除名称/文字草稿也不保证擦除已捕获意图中的名称、标题或提示词；原意图仍可能为恢复保留这些文字。本片没有新增删除、清理或隐私擦除能力。

## 隐私与备份

四个旁文件位于本机私有工作区，使用明文格式，不经凭据保险库加密。字段白名单不保存账号、密钥、连接令牌或认证设置，但自由输入的名称和提示词仍可能包含用户私密内容，不能宣称“绝对无敏感数据”。

四个旁文件均排除于当前离线工作区备份。因此备份可保留已保存业务数据，但不会把这些未提交草稿、旁文件意图或最近项目位置带到恢复副本。恢复工作区不读写这四类记录；原允许的新本地导入、编辑与导出仍可显式操作，继承任务的隔离限制继续生效。
