# Mioon 首次试用与工作区指南

第一次先跑通一个不花费模型费用的小项目：导入原创测试图片 → 首帧参考 → 两个模拟版本 → 固定版本加入时间线 → 剪辑 → 真实 MP4 导出。模拟视频带有 `SIMULATED MOCK` 标识，是可播放的测试画面，不会按提示词生成真实产品或角色。

当前源码/候选状态与更短的“直接导入 → 剪辑 → 导出”浏览器路线见[核心试用一页指南](CORE-TRIAL.zh-CN.md)。本页保留较完整的模拟版本练习；历史验收记录不等于当前候选的最终检查已通过。

## 先确认入口和验证范围

- 这里的 Mac 路线是**从源码运行开发版**，不是已验证的 Mac 安装包。需要 Node.js 24 或更新版本、pnpm 11.25.0，以及从可信来源安装的 FFmpeg / ffprobe。
- 现有原生运行证据来自 Linux。Mac 原生启动、文件选择、视频工具、完整退出重启与“保存视频”对话框仍需在真实 Mac 验证；签名、公证和安装升级也尚未验证。Windows 私有存储 ACL 尚未实现，当前会拒绝启动业务存储。
- 浏览器试用通过，只能说明该浏览器和本地服务的流程通过。浏览器下载不等于 Electron 原生“保存视频”已通过；后端和浏览器重启也不等于原生应用重启。
- 所有真实生成默认关闭。第一次试用无需供应商 API 密钥，也无需设置 Agent。不要为了试用把密钥填到提示词、浏览器控制台或聊天里。

在项目根目录执行：

```sh
pnpm install --frozen-lockfile
node scripts/tooling.mjs doctor
node scripts/tooling.mjs build --channel=development
pnpm desktop
```

`build` 顺序构建页面和桌面暂存内容；不要只更新后端而继续打开旧页面。`doctor` 检查通过不代表 Mac 原生就绪，也不替代一次实际媒体导出。

首次桌面启动会要求选择本机的 `ffmpeg` 和 `ffprobe` 可执行文件。它们没有捆绑在应用中；FFmpeg 还需提供 `libx264` 和 `aac` 编码器。也可用 `MIOON_FFMPEG_PATH`、`MIOON_FFPROBE_PATH` 明确提供两者的绝对路径。详见 [桌面运行](DESKTOP.md)。

开发版默认使用 `app.starroy.mioon.dev` 的独立数据目录，不会自动接管旧版或正式版项目。若提示数据目录不安全，先保留原数据，按 [私有存储恢复](PRIVATE-STORAGE.md) 检查；不要删除令牌、数据库或锁文件来绕过提示。自选目录必须是真实绝对路径；Mac 的 `/tmp`、`/var` 等符号链接别名可能被拒绝。

只用浏览器时，完成页面构建后运行 `pnpm start`，打开终端显示的本机地址，默认是 `http://127.0.0.1:4318`。首次启动创建 `data/access-token`；仅在自己的终端读取，并填入本地登录框。桌面版会自动认证。云端电脑的 localhost 不能直接当成自己 Mac 上的 localhost。

## 十步跑通第一次试用

### 1. 创建一个空项目

点击“创建第一个项目”，输入容易辨认的名称，例如“首次试用”。已有项目时，从顶部项目菜单选择“新建项目”。此时应进入“画板”，左侧素材库为空。不要直接使用原有工作项目做测试。

### 2. 导入一张测试图

点击左侧“导入图片 / 视频 / 音频”，选择仓库中的 `examples/synthetic/reference.png`，或你明确选择的测试图片。素材库应出现缩略图。导入只是复制到本地工作区，不会自动上传给生成平台，也不会自动成为画板节点。

支持 PNG/JPEG/WebP、MP4/WebM、WAV/MP3/M4A，每个文件不超过 30 MiB。

### 3. 建立镜头与真实首帧参考

点击“添加镜头”，填写“画面描述”并“保存修改”。在图片素材卡片上点击“加入画板”；选中图片节点，在右侧“首帧参考连接”选择目标镜头，再点“连接为首帧参考”。镜头应显示“已连接首帧参考”，绿色连接参与生成。

这次用单个“添加镜头”最直接。“创建三镜头结构”会把素材库中的第一张图片设为三个镜头的手动参考图；如果之后想改用节点连接，需先在镜头里“清除手动参考图选择”并保存。灰色视觉连线只整理思路，不参与生成。

### 4. 生成第一个模拟版本

选中镜头，在“生成引擎”确认服务商带有“本地模拟”。选择 2 秒、9:16，保留正常模拟场景，点击“生成镜头”；有草稿时按钮会是“保存并生成镜头”。

“任务中心”显示进度。完成后关闭任务中心，镜头应出现 V1 和“模拟”标记，并能播放真实测试视频。模拟画面不会忠实描绘提示词或参考图，这里验证的是流程和引用快照。

### 5. 生成 V2，再明确选用 V1

改写提示词，再次生成。打开“版本历史”，点击“比较”查看两个视频。关闭比较后，选用 V1。旧版本和旧提示词快照应仍在；重新生成不覆盖 V1。

“选用”决定镜头预览和后续分镜导出所用版本，不会自动替换已经加入时间线的片段。

### 6. 把固定版本加入剪辑

在 V1 卡片点击“将此固定版本加入时间线”，或在创作参数中用“当前选用版本 → 时间线（固定副本）”。成功后进入“剪辑”，并选中新增片段。

点片段属性里的“返回来源”，应定位 V1。现在把镜头改选 V2，再回到“剪辑”：已有片段仍引用 V1。这就是固定来源。需要换源时，应使用片段属性中的显式替换流程。

### 7. 做一次可撤销的裁剪

先点时间线的“渲染预览”并等到完成。选中这个 2 秒片段，在右侧把“素材入点”改为 15、“持续帧数”改为 45，保留“开始帧”0，点“保存片段”。

30 帧等于 1 秒：这会取源视频第 0.5 秒到第 2 秒，得到 1.5 秒片段。原来的合成预览会显示旧快照。点一次“撤销”，再点“重做”，确认裁剪恢复。原素材与两个生成版本都应保留。

### 8. 更新真实合成预览

切到“时间线合成”，点“更新预览”或“渲染预览”。完成后旧快照提示消失，预览应可播放和拖动播放头。时间线预览由 FFmpeg 实际渲染，不是即时重算所有效果的播放器。

“源素材快速查看”播放源文件；它不包含片段音量、淡入淡出或多轨混音。要检查最终画面和声音，请用时间线合成预览。

### 9. 检查、确认导出，再保存文件

点顶部“导出时间线”。右侧会打开“交付检查”的“本次导出”页，另一个页签是“导出记录”；**打开页面不会立即检查或创建导出**。可填写“本次成片名称”，留空沿用默认文件名；非空名称按原文校验，接受后原样固定在这次导出中，不自动取项目名，也不改名旧记录。此例保留“原始合成尺寸”和“标准 · CRF 23”；也可为本次导出选择短边 360/1080、CRF 画质或平均目标码率。1080 是放大 720 合成，不增加原画细节。点击“检查本次设置”，等本机编码能力与素材检查完成；确认当前已保存时间线“检查通过”，再点“确认导出”。修改名称或设置后须明确重新检查。

在同一右栏切到“导出记录”，等待该次时间线导出完成，再点该行“下载”。记录保留接受时的名称、时间线修订和导出规格，之后改项目名或编辑时间线不会覆盖旧成片。不要把“时间线预览”那一行误认成正式导出。桌面版会打开原生“保存视频”对话框；已命名成片建议使用安全化名称加短导出编号的 MP4 文件名，显示名称本身保持原文。仍由你选择保存位置，同名覆盖需原生确认。必须实际保存文件并重新打开播放，才算完成交付。此例应得到约 1.5 秒、720×1280、30fps 的 H.264/AAC MP4；模拟源视频无声音，导出包含补齐的静音音轨。命名范围与候选验收见[成片命名](NAMED-DELIVERIES.md)。

未保存的镜头、片段和源范围草稿不进入检查或导出。保存草稿后，旧报告会失效，需要重新检查。素材缺失或损坏时先处理错误；“检查未完成”不等于通过。检查报告也不等于导出成功，仍要等实际渲染完成。

### 10. 退出、重新打开，核对保存结果

等顶部不再显示“保存视图…”或“正在同步”，正常退出应用，再重新启动并选择同一个项目。不要只关闭最后一个 Mac 窗口来模拟完整退出；Mac 的关闭窗口与退出应用行为不同，实机行为仍待验证。

核对导入图、V1/V2、当前选用 V2、固定引用 V1 的 45 帧片段、撤销历史和旧导出都仍在。“任务中心”应没有待确认的本地编辑请求，重新打开不应额外生成新版本或导出。

工作区记忆属于每个项目；它不承诺全局自动恢复“最后打开的项目”。崩溃、强杀或断电时，尚未确认保存的草稿与视图不保证恢复。

## 画板、分镜和时间线分别控制什么

- 画板：素材节点、文字、镜头、参考连接、生成参数与版本比较。节点位置只是空间布局，不决定成片播放时间。
- 分镜：按镜头顺序组织故事。默认收起，可从“面板”菜单或分镜入口展开。“导出分镜”按这个顺序使用各镜头的已选版本。
- 剪辑：左侧素材库、中央大预览、右侧片段属性、下方多轨时间线。“导出时间线”使用这里的时序、叠层和声音。
- 空时间线可以明确执行“从分镜建立时间线”，复制当时选中的固定版本；之后两者独立，不会自动跟随改选。
- “返回来源”只定位确切历史版本，不会替你改选镜头版本。

同轨片段不能重叠，不同画面轨可以叠放；上层画面覆盖下层。画面轨接收图片和视频，音频轨接收音频。轨道的画面显示和声音静音分别控制；没有画面时是黑色，没有声音时是静音。

## 当前已有的剪辑能力与限制

已实现：整数帧剪辑与源入点、固定来源、显式替换片段来源、所选片段分割、持久化撤销/重做、拖动吸附、保存源范围、收藏/拒选素材、音频淡入淡出、可选源音频波形、合成预览及导出前检查。

- 分割：把播放头放在所选片段内部，点“分割”或 Cmd/Ctrl+B。不会移动其他片段；切在淡入淡出内部等不支持的情况会拒绝。
- 替换来源：在片段属性中明确选择并核对新来源。不会因为重新生成或改选版本而自动替换；时长或类型不兼容时会拒绝。
- 波形：需要明确开启/请求，显示源音频，不是音量、静音、淡入淡出后的最终混音。无波形的素材仍可编辑。
- 时间线固定30fps，初始空白项目可从项目菜单的“时间线输出规格”选择720×1280、1280×720或720×720；开始编辑后不能直接切换。分镜导出仍为720×1280。最多12条轨道、100个片段、10分钟；没有任意分辨率/帧率、复杂转场、关键帧动画、变速、多人协作或云同步。见[范围与限制](TIMELINE-OUTPUT-FORMATS.md)。
- 主体/风格统一、多关键帧和运动参考等完整工作流仍属后续方向；首帧连接不保证角色、产品或风格一致性。

## 调整面板与保留草稿

面板固定在工作区边缘，不是可任意拖离工作区的窗口。拖左右内侧边缘调整宽度，拖时间线上边缘调整高度；松开后保存，Escape 取消。键盘聚焦边缘后，方向键每次 10px，Shift+方向键每次 50px，Home/End 到边界；双击恢复默认尺寸。

减号收起面板；边缘入口或顶部“面板”菜单重新展开。画板和剪辑分别保存尺寸与开关。收起不丢草稿，隐藏媒体暂停；已经提交的后台任务继续。窄窗口一次显示一个面板，可从底部切换素材、画板/预览、属性和时间线。

“重置当前工作区布局”只重置当前模式面板。切换模式、对象或项目时若有未保存草稿，会先要求处理；取消或 Escape 留在原处。多窗口视图冲突时，核对“载入已保存视图”，不要把它当成保存业务草稿。

## 任务中心：哪些请求能跨完整重启恢复

“本地编辑请求”把以下 **19 类**操作的原请求编号和完整参数保存在本地数据库中：

- 轨道添加、轨道更新
- 片段添加、更新、替换来源、移除、分割
- 从分镜建立时间线、撤销、重做
- 首帧参考连接、断开
- 主体创建、追加版本、设置镜头关联（主体/风格规划不自动提交给供应商）
- 初始空白时间线输出规格设置
- 手动字幕添加、更新、移除

这些记录先保存，再尝试执行。完整重启后可以重新发现；打开任务中心或重启本身不会自动执行未决编辑。点击“恢复同一请求”会先核对原记录，需要执行时使用已保存参数，不使用你当前尚未保存的草稿。已确认的终态可“确认并关闭记录”；关闭记录不等于删除历史身份。

下面 **8 类**画板/素材操作的待确认请求，仍依赖当前浏览器会话：镜头创建、更新、排序，节点创建、更新，版本选用，源范围保存，素材标记保存。`timeline.render`（预览/时间线导出）以及生成、重试和分镜导出的待确认提交参数也没有迁入这 19 类协调器。已落库的生成任务、版本和导出结果仍持久保存，不能把“会话记录可能丢失”误解成项目内容不保存。

导入、波形和 Agent 提案审批各有自己的路径；不能笼统宣称所有操作都能由任务中心跨重启恢复。还存在的旧会话记录若属于这 19 类，可明确转存；转存本身不执行操作，已丢失的旧会话无法从当前画面反推原请求。

恢复列表加载失败时，这类编辑会暂时被阻止。先使用任务中心的“重新载入任务”，不要换新请求重复提交。服务商提交状态未知时，先核对已有任务；“停止等待”不代表远端取消或停止计费。

试用协调器最多保留 4096 条身份记录、64 MiB 逻辑预留；到达上限会阻止新任务，不会静默清除历史。长期大量编辑的归档/压缩策略尚未实现。这不是数据库或 WAL 文件的实际大小上限。任务参数与项目保存在普通本地 SQLite 中，未作保险库加密。详见 [任务恢复](TASK-RECOVERY.md)。

## 示例、备份与帮助

想先观察已有多轨编排，可按 [示例说明](../examples/README.md) 把关闭状态的示例复制到全新的私有工作区，再启动副本。不要直接运行或改写仓库里的公开示例数据目录。

备份前正常关闭后端，整体保存工作区及其媒体，不要只复制 SQLite 主文件。不要删除结果文件或恢复记录来清空错误。更多规则见 [时间线](TIMELINE.md)、[交付检查](EXPORT-PREFLIGHT.md)、[工作区视图](WORKSPACE-PREFERENCES.md)和 [桌面运行](DESKTOP.md)。

### 手动字幕

时间线已有媒体后，点击「字幕」进入右侧属性页，在播放头处新增并保存文字与起止帧。固定底部居中排版，每条最多两行、每行20个字符；支持的常用汉字和标点以即时校验为准。开始帧包含、出点不包含，字幕不得重叠或超出媒体时长。切换右侧标签/收起面板保留草稿，跨项目或改变选择会检查未保存修改。

源素材播放不显示烧录字幕；保存后用时间线「渲染预览」核对实际画面。导出使用同一固定字体和已保存快照。旧分镜导出不加入字幕。更短的媒体编辑若会截断字幕将拒绝，须先明确调整字幕。响应丢失时查看任务中心恢复同一请求，不重新整批提交。详见[手动字幕范围](MANUAL-SUBTITLES.md)。
