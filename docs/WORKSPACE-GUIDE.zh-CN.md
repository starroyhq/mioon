# 画板与剪辑：同一项目的两种工作空间

顶部“画板 / 剪辑”切换整个工作空间。素材、镜头、固定版本、任务、时间线和导出仍属于同一项目，API、CLI、MCP 与界面共用同一份数据。

## 画板：构思、参考和生成

左侧素材库用于导入、搜索和筛选；中央无限画布组织图片、视频、音频、文字和镜头；右侧显示所选镜头或节点的属性。画板没有底部时间线。分镜顺序默认收起，需要调整故事顺序时再展开。

节点位置只是空间布局，不是成片播放时间。图片节点的“连接首帧到镜头”或绿色输出/输入端口会建立真实的首帧参考；绿色线参与生成，灰色虚线只整理思路。每个镜头最多绑定一张首帧图片。

镜头已有手动参考图时，先明确清除手动选择并保存，才能连接。断开首帧连接会清除该连接拥有的生成参考，保留素材、节点、旧版本和已经提交的任务快照。改图或切换文生视频前先断开。面板有未保存修改或连接操作结果待确认时，先保存、放弃或恢复原请求。

镜头每次生成都有独立版本。选用其他版本只改变镜头后续的预览和分镜导出，不会改写已加入时间线的片段。素材库用“生成”标记生成来源；“版本历史”保留各版本的生成参数与参考快照。

## 剪辑：预览、编排和导出

左侧素材库、中央大预览、右侧片段属性，以及下方横跨工作区的多轨时间线构成剪辑空间。这里不显示画布节点或分镜板。

预览可以切换：
- 源素材：查看原素材或所选片段的源内裁剪范围
- 时间线合成：查看真实渲染的叠层、空隙与混音，与导出使用同一个合成器

修改时间线后，上一次预览会标为旧快照。点“更新预览”重新渲染，完成后播放新的结果。播放推动播放头；点击时间标尺或输入帧数也可定位。切回画板会卸载预览播放器并停止播放。

片段属性包括轨道、开始帧、持续帧数、素材入点、画面矩形和音量。“开始帧”是成片位置，“素材入点”是从源视频/音频哪一帧开始读取。30 帧等于 1 秒。编辑后点“保存片段”。

时间线规则：
- V 画面轨接收图片/视频，上层覆盖下层，可用矩形大小与位置做画中画
- A 音频轨接收 WAV、MP3、M4A；未静音视频的原声一起混合
- 同一轨道片段不能重叠，不同轨道可以叠放
- “画面开/隐藏中”和“声音开/静音中”分别控制画面与声音
- 无画面时为黑色，无声音时为静音
- 撤销/重做与 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z（Ctrl+Y）使用持久化时间线历史；不会撤销生成任务、花费或固定版本

## 调整和收起面板

素材库在左侧，属性在右侧，剪辑时间线在底部。它们固定在工作区边缘；圆角和留白营造悬浮外观，不是可以任意拖离工作区的窗口。

- 拖动素材库右边缘或属性左边缘调整宽度，拖动时间线上边缘调整高度。只在松开后保存尺寸，Escape 取消当前拖动。
- 键盘 Tab 可聚焦调整边缘；方向键每次 10px，Shift + 方向键每次 50px，Home/End 到当前可用边界。双击边缘恢复该尺寸默认值。
- 点面板标题的减号收起；桌面边缘始终留有展开入口，顶部“面板”菜单也可选择。普通节点或片段选择不会自动打开已收起的属性。
- “重置当前工作区布局”只恢复当前画板或剪辑的面板尺寸与开关，不重置选择、播放头、缩放或滚动，也不产生时间线撤销记录。
- 画板侧面板覆盖画布边缘。收起或改变宽度只改变遮挡，不自动缩放、平移或重排节点。剪辑面板占用独立空间，不遮住预览。
- 收起面板保留当前草稿、选择和滚动位置，不要求放弃修改。隐藏的音视频立即暂停，再展开也不自动播放；已经明确提交的保存、生成和后台任务继续运行。
- 窄屏或较矮窗口一次显示一个面板。底部可选择素材、画板/预览、属性；剪辑另有时间线入口。选择入口会重新打开已收起的面板。窗口恢复宽敞后会继续使用原来的首选尺寸。

## 两个明确的跨模式入口

“加入时间线”把当前素材或明确选中的历史版本加入剪辑。加入成功后进入剪辑并选择新片段。加入使用固定素材 ID，切换镜头版本不会替换它。

“返回来源”在片段属性中。生成素材会回到画板中的对应镜头，并在版本历史标出片段真正引用的版本。这个查看操作不会改动 selectedVersionId、片段 assetId 或时间线历史。普通导入素材有唯一关联节点时定位该节点；没有唯一关联节点时查看原素材，不猜测节点或版本。

## 切换、刷新与恢复

每个项目分别记住：
- 当前画板/剪辑模式
- 画板的缩放、平移、选择、版本标签和分镜展开状态
- 剪辑的片段选择、源素材选择、播放头、时间线缩放与滚动

画板和剪辑各自的面板尺寸、收起状态也分别保存在当前项目的本地后端数据库中。它们是视图偏好，不是项目业务数据；CLI/MCP 的外部编辑不会强行切换模式。打开项目时恢复已确认保存的偏好，浏览器刷新和 Electron 正常退出重启都可恢复，临时认证会话与随机后端端口不变。它不记住全局最后打开的项目。多窗口冲突会停止保存并提示载入已保存视图；断网时可继续使用临时视图，但未确认写入、崩溃或强制退出不能保证恢复。详见[视图偏好与退出限制](WORKSPACE-PREFERENCES.md)。

有未保存属性修改时，切换模式、对象或项目会要求先处理草稿。取消或 Escape 留在原处，输入不变。确认放弃只丢弃未提交草稿。关闭整个页面仍由浏览器原生未保存警告保护。

网络中断或响应丢失时，任务面板保留原请求。点击“恢复同一请求”核实原操作，不生成新的请求 ID。模式切换不会取消服务端任务或清空恢复记录。后台完成、外部编辑或迟到的响应不能把你从正在使用的模式或项目拉走。

## 分镜与时间线仍然独立

画板中的分镜顺序决定“导出分镜”的顺序，时间线决定“导出时间线”的多轨编排。空时间线可明确执行“从分镜导入”；复制的是当时选中的固定版本，之后两者独立。

## 试用示例与范围

1. 按 README 启动 examples/multitrack-project，选择顶部“剪辑”，查看多轨画面与声音。
2. 点击星形卡片片段，改开始帧或矩形位置并保存。预览会标为旧快照。
3. 点“更新预览”，确认后“导出时间线”。回到“画板”继续构思，不会改动编排。

输出仍固定为 720×1280、30fps；最多 12 轨、100 片段、10 分钟。当前不包含替换片段、波形、多画幅、复杂转场、关键帧或变速。真实 AI 调用仍需独立授权；验收只使用原创合成素材和本地模拟供应商。
