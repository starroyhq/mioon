# Mioon 安装与首次运行

Mioon 是内置视频 Agent Mio 的创作工作台。你可以先用自己的图片、视频和音乐完成一个短片，再按需连接 Mio 或生成服务。**导入、剪辑和导出已有素材不需要 AI 账号或密钥**

本指南适用于 **v0.1.0 桌面版**。前往 [v0.1.0 发布页](https://github.com/starroyhq/mioon/releases/tag/v0.1.0)下载安装包。支持的平台和功能范围见[发布说明](releases/v0.1.0.zh-CN.md)。

## 1. 选对下载文件

在发布页展开 **Assets（附件）**，按电脑选择：

| 你的电脑 | 下载文件 |
| --- | --- |
| Mac，Apple Silicon 芯片（M 系列） | `mioon-0.1.0-mac-arm64.dmg` |
| Mac，Intel 处理器 | `mioon-0.1.0-mac-x64.dmg` |
| Linux 或 Windows | 本版暂不提供桌面安装包 |

在苹果菜单的「关于本机」查看芯片或处理器。两个 DMG 均在 macOS 15 上构建，使用 Developer ID 签名并经 Apple 公证。

`Source code` 是给开发者的源码压缩包，`SHA256SUMS` 和 `release-manifest.json` 用于核对下载文件，都不是安装程序。使用桌面安装包无需安装 Node.js、pnpm 或下载整个源码仓库

## 2. 安装应用

### macOS

1. 打开下载的 `.dmg`
2. 将 **Mioon** 拖到“应用程序”文件夹
3. 从「应用程序」打开 Mioon。安装完成后可以在 Finder 推出安装磁盘

若系统阻止打开，请核对下载来源、架构和 `SHA256SUMS` 中的校验值。仍无法打开时，请反馈系统提示和 macOS 版本。请勿删除隔离属性或关闭 Gatekeeper。

## 3. 准备视频工具

Mioon 需要 **FFmpeg** 处理视频和声音，使用 **ffprobe** 读取素材信息。它们是独立的命令行工具，**没有包含在 Mioon 安装包中**

首次启动时可点「下载并安装」，使用 Mioon 提供的 FFmpeg 7.1.5 和配套的 ffprobe。提示会显示适合当前处理器的下载大小。点「下载并安装」后，Mioon 会校验下载的文件并安装到应用数据目录。工具按 GPL 许可分发，源码见对应的[工具发布页](https://github.com/starroyhq/mioon/releases/tag/media-tools-7.1.5-1)，构建方式见[视频工具说明](MEDIA-TOOLS.md)。

也可以使用自己安装的工具。如果电脑上已有这两个工具，可以继续使用符合要求的版本。否则从 [FFmpeg 官方下载页](https://ffmpeg.org/download.html)查找适合系统和处理器的编译包或软件包；FFmpeg 项目本身提供源码，页面列出的预编译工具来自相应提供者。不要只下载源码、安装器或只有 `ffmpeg` 而没有 `ffprobe` 的包

自己安装时，建议选择 **FFmpeg 7.1.5 或更新的完整功能构建**，并使用配套的 ffprobe。项目 CI 以 7.1.5 为媒体工具基线；版本号本身不能保证包含所有功能。FFmpeg 4.4 不支持应用当前使用的部分命令参数，不适合作为本版工具

| 使用场景 | FFmpeg 需要提供 |
| --- | --- |
| 导出常见 MP4 | H.264 编码器 `libx264`、音频编码器 `aac` |
| 手动字幕与本地模拟画面 | `subtitles`、`drawtext` 滤镜及对应字体支持 |
| 颜色处理、响度分析与匹配 | `zscale`、`loudnorm`、`ebur128` 滤镜 |
| 图片与缩略图处理 | PNG、WebP 编解码支持 |

### 已使用 Homebrew 的 Mac 用户

可以参考 [Homebrew 的完整 FFmpeg 配方](https://formulae.brew.sh/formula/ffmpeg-full)，在终端安装并显示工具位置：

```sh
brew install ffmpeg-full
echo "$(brew --prefix ffmpeg-full)/bin/ffmpeg"
echo "$(brew --prefix ffmpeg-full)/bin/ffprobe"
```

记下最后两行路径，供下一步选择。`ffmpeg-full` 不会默认替换系统命令路径；在 Mioon 中直接选择它，不需要强制覆盖原有 FFmpeg。尚未安装 Homebrew 时，可先阅读其[官方安装说明](https://brew.sh/)，再决定是否采用这种方式

## 4. 第一次打开 Mioon

出现视频工具提示时：

- 使用 Mioon 提供的版本时，点「下载并安装」。关闭进度窗口可以取消安装。安装和检测通过后会自动保存路径并继续启动。下载或校验失败时，回到工具选择提示重试，或改选自己的工具。
- 使用自己安装的工具时，点「选择已安装的工具」。先选 **`ffmpeg` 可执行文件**，再选 **`ffprobe` 可执行文件**。检查通过后，Mioon 会保存路径并继续启动。

在 Mac 文件选择框中，可以按 **⌘⇧G** 粘贴可执行文件的完整路径。以后可在「设置 › 视频工具」更换工具。下载 Mioon 提供的版本后，点「重启本地服务」使它生效。手动更换时，用「浏览…」选择两个可执行文件，点「保存路径」，再退出并重新打开 Mioon。

桌面版会自动连接本机服务，正常情况无需注册账号或手动复制访问令牌。进入后可在设置里切换语言、主题，再到“视频工具”检查当前工具状态

首次启动必须检查通过 `libx264` 和 AAC 编码器；缺少时换完整构建，或改用 Mioon 提供的版本。通过启动检查仍不代表字幕、颜色等全部能力齐全；进入后可点“检测工具”，并先完成下面的小项目。完整步骤见[使用指南的首次启动一节](USER-GUIDE.zh-CN.md#首次启动配置视频工具)

## 5. 先完成一个自己的小短片

1. **新建项目**：为手机画面选竖屏，也可以选横屏或方形
2. **导入素材**：先用几张不重要的图片、一小段视频或音乐
3. **加入剪辑区**：排好顺序，调整片段长短和音量
4. **更新预览**：查看真正合成的画面和声音
5. **导出 MP4**：核对导出设置，完成检查后确认导出；完成后下载到自己选择的位置，并打开视频播放

关闭导出窗口不会取消已接受的导出任务，可以在任务或导出记录中继续查看。画板用于整理参考、文字与镜头；项目文件、素材和本机记录的使用见[使用指南](USER-GUIDE.zh-CN.md)

准备使用 Mio 时，再按 [Mio 使用说明](MIO-GUIDE.zh-CN.md)配置模型和发送授权。图片或视频生成使用各自的服务设置。模型、连接测试和生成请求都可能向外部服务发送内容并产生费用；付费生成默认需要确认，但执行策略可以由你调整。停止等待不保证已发出的请求取消或费用退回

## 6. 保存、更新与遇到问题

项目内容保存在 `.mioon`，媒体单独保存；版本历史、Mio 对话、任务和草稿在本机记录中，不随项目文件自动携带。当前没有自动云同步。重要作品请另外保管项目文件和媒体，需要的本机记录也要保留；自动备份只保存项目文件，不含媒体或聊天

打开项目后，点击顶部项目名称，选择「版本历史…」，再切换到「自动备份」。点「查看」可以只读查看备份，点「恢复为新项目…」可以选择保存位置，从备份创建独立项目。版本与备份的区别见[使用指南](USER-GUIDE.zh-CN.md#版本历史与自动备份)。

**本版没有自动更新**。更新前先备份、正常退出 Mioon，再从发布页下载与电脑架构匹配的新安装包。保留原项目、素材和本机记录。

在 Mac 上关闭最后一个窗口后，Mioon 仍会运行。完全退出时，在应用菜单选择「退出 Mioon」或按 **⌘Q**。菜单栏图标中的「隐藏到托盘」会保留窗口内容。

| 遇到的情况 | 先做什么 |
| --- | --- |
| 找不到工具或提示不是 FFmpeg | 重新选择已解压、可执行的 `ffmpeg` 与 `ffprobe` 文件 |
| 能打开，但字幕、颜色或导出失败 | 检查视频工具能力；记录报错，不把缺滤镜当成项目损坏 |
| 提示数据目录、权限或锁有问题 | 保留原数据与提示，不直接删除文件；查看[私有存储说明](PRIVATE-STORAGE.md) |
| 模型或生成失败、结果未知 | 保留原任务并查看详情；不要反复提交可能计费的同一操作 |

反馈到 [GitHub Issues](https://github.com/starroyhq/mioon/issues) 时，写明 Mioon 版本、系统、处理器、FFmpeg 版本、操作步骤和错误提示即可。截图前遮住密钥、令牌、私人聊天与素材；无需上传整个工作区

各平台和服务的支持范围见[发布说明](releases/v0.1.0.zh-CN.md)。
