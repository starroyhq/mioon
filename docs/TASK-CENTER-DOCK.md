# 任务中心：右侧共用工作区

基线：`c8f2c03f8ae19f1d48878a944afeea2cd0a92a42`。本片将已有任务中心从遮罩抽屉移入右侧第五个“任务”页签；不增加业务 API、持久化格式、自动任务或轮询。

## 使用与范围

- 顶部任务入口和需要人工处理的当前请求可打开“任务”；与属性、Agent、图像、交付共用可折叠右栏。
- 任务内容独立滚动。默认右栏宽 310px，最小 240px；窄栏页签可横向滚动，共用收起按钮保留在页签外。
- 切换页签、收起、重新展开保留原编辑草稿。打开任务列表本身不执行恢复、重试、生成或确认。
- 本地编辑请求、当前会话待确认请求和既有视频生成任务保留原功能。它不是所有图像、Agent、草稿或导出记录的统一数据库；这些记录继续在各自入口查看。
- “查看镜头”验证当前项目、任务及镜头的关联，并通过原草稿离开确认。只有目标仍有效、当前选择未变化时才转入属性。取消确认不会导航；迟到的旧选择不能覆盖新选择。
- 模型任务的付费确认及未知结果警告保留。切换/隐藏任务视图后，尚未确认的任务来源操作不再获得继续执行的权限；已交给后端的动作不能因此宣称取消。

## 请求与视图的边界

TS 的固定视图令牌绑定项目、工作区身份、项目/导航 epoch 和面板选择；TSX 生命周期令牌另行绑定该可见面板实例。隐藏后重新显示不会复活旧回调。

恢复按钮先查原任务，再决定是否明确执行原请求。若查询等待期间离开任务视图，后续执行被阻止。若原请求已经执行、随后收到严格确认回执，则仍按原机制确认记录及刷新当前项目，不因为切页丢掉确认；提示或打开任务页不能抢占用户的新页签。保留原 requestId、CAS、历史回执和恢复工作区的 held 限制。

异步失败自动打开任务页也检查动作发起时的面板选择，包括直接调用的时间线规格、字幕和主体保存。付费重试的视图绑定只存在于本地审阅状态，不改变提交参数或扩大授权。
