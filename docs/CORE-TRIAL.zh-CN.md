## 最短入口：自己的电脑、本机浏览器、无需密钥

Linux 是目前已有运行证据的路线；Mac 源码构建和浏览器流程仍须区分记录，当前完整试用尚未认证。Windows 的私有存储 ACL 后端仍不可用，本机 Web 和桌面后端都会拒绝启动，不只是安装包尚未验收。

准备 [Node.js 官方发行版](https://nodejs.org/en/download) ≥24、按[官方说明](https://pnpm.io/installation)安装固定 pnpm `11.25.0`，以及可信来源的 FFmpeg/ffprobe（需 `libx264`、`aac`；Mock 另需 `drawtext`）。工具已符合要求就不必重装。使用确认过的同一份源码和新试用数据目录；不要覆盖已有项目或复制 Linux 的依赖/可执行文件到 Mac。

在源码根目录逐条运行，前一步成功后再继续：

```sh
node --version
pnpm --version
pnpm install --frozen-lockfile
pnpm run doctor
pnpm build
test ! -e "$HOME/Mioon-core-trial-20261012" &&
  env -u MIOON_TOKEN -u MIOON_DIST_DIR MIOON_DATA_DIR="$HOME/Mioon-core-trial-20261012" MIOON_ENABLE_LIVE_PROVIDER=0 pnpm start
```

最后两行仅在示例试用目录不存在时启动；若目录已存在，本次不会启动服务，请换一个确认未用过的名字并保持两处路径一致，不删除原目录。后续重开应去掉这项“目录不存在”检查，仍明确使用首次选定的同一 MIOON_DATA_DIR。

安装沿用官方依赖来源、锁文件与现有安装策略；不要为下载错误改锁或关闭校验。doctor 通过不证明媒体导出或原生平台通过。上面的 build 构建浏览器页面；无需先启动 Electron，也无需配置 Agent、供应商或 Images 密钥。

保持服务终端运行，在**同一台电脑**打开终端显示的地址，默认 `http://127.0.0.1:4318`。上述示例首次启动在 `$HOME/Mioon-core-trial-20261012/access-token` 创建私有令牌；只在自己的终端读取它并填入本机登录框，不发到聊天、URL、截图或共享文件。使用其他 MIOON_DATA_DIR 时，令牌位于那个目录；不要误读旧的 `data/access-token`。云电脑的 localhost 属于云电脑，不是用户电脑可直接访问的试用网址，也没有公开托管入口。

## 五步完成一次本地交付

1. 新建试用项目。需要横屏/方屏时，在任何编辑前选择“时间线输出规格”：720×1280、1280×720、720×720，均为30fps；开始编辑后不能直接切换。
2. 导入仓库的 `examples/timeline-synthetic/scene-a.png` 和 `scene-b.mp4`，从素材“加入时间线”进入剪辑。导入只复制到本地工作区，不会自动上传给模型。
3. 保存一次片段裁剪/移动，可试撤销、重做或手动字幕。点“渲染预览”/“更新预览”，查看实际合成画面和声音；源素材播放不显示剪辑、混音或烧录字幕。
4. 点“导出时间线”，在右侧“交付检查”→“本次导出”填写可选的“本次成片名称”，核对画质/尺寸，再明确点“检查本次设置”。检查通过后点“确认导出”；改名称、设置或已保存时间线后必须重新检查。打开页面不会自动检查或导出。
5. 在同一右栏“导出记录”等待完成并下载，实际打开 MP4 检查播放。正常关闭服务、用同一数据目录重开，再核对旧记录。已命名记录保留接受时的原文名称、修订和规格；改项目名或继续剪辑不会覆盖旧成片。桌面原生另存为建议安全化名称加短导出编号，由用户选择目标并确认覆盖。

更完整的模拟版本练习见[工作区指南](WORKSPACE-GUIDE.zh-CN.md)。桌面是可选入口：完成网页构建后运行 `pnpm desktop:build`、`pnpm desktop`，并按提示选择本机媒体工具。已有实际 Linux 打包应用、原生另存为及正常重开证据见[命名验收](NAMED-DELIVERIES.md#measured-acceptance-2026-10-12)；本轮最终源码检查已经通过；这些 Linux 结果仍不能证明 Mac/Windows 可用。[Mac 指南](MAC-SOURCE-TRIAL.zh-CN.md)只说明源码路线。

## 已有范围与必须保留的限制

- 支持本地图片/视频/音频导入、固定来源多轨剪辑、三种30fps输出规格、手动固定样式字幕，以及[MP4/H.264导出设置](EXPORT-SETTINGS.md)。命名增量冻结每次名称/设置与导出记录，不是多序列、批量导出或任意帧率/编码器。
- [备份与安全恢复](WORKSPACE-BACKUP-GUIDE.zh-CN.md)使用本机离线命令：原始受支持备份只能恢复到全新独立目录。恢复分支允许新的本地导入/编辑/预览/导出，继承任务/审批/未知结果保持历史状态，不重新执行。首版不能新生成、运行 Agent/Comfy、抽帧、解码波形或再次备份；必须保留原始备份。备份数据库含私密明文聊天/提示词，不等于加密保险库。
- 可选内置 Agent 的范围是聊天、明确同意的当前项目有限读取，以及逐次审核的镜头标题/提示词修改或所选片段同轨起点移动。它没有任意编辑、备份/恢复或付费媒体生成工具权限；Agent 模型发送本身仍可能计费，首次核心试用不需要它。外部 CLI/MCP 另按共享契约和原请求恢复规则使用。
- Mock 是带标记的合成流程测试，不证明真实生成质量、角色一致性或供应商可用。真实模型仍需另行核实配置、明确素材范围与费用/预算批准；密钥只通过安全配置输入，永不发到聊天。视频的 `MIOON_ENABLE_LIVE_PROVIDER=0` 不是 Agent、Images、Comfy 等所有联网功能的总开关。

这里是本地、单用户、有限源码试用。没有自动云同步，也没有已验证的 Mac/Windows 安装包、签名/公证或自动更新承诺。
