V2 shared timeline contract (fixed 30fps; dimensions 720x1280)
- project.get returns timeline {id,projectId,revision,fps:30,width:720,height:1280,tracks:[],clips:[],durationFrames,createdAt,updatedAt}.
- tracks {id,name,kind:'video'|'audio',orderIndex,hidden:false,muted:false}. Larger video orderIndex renders above smaller; UI higher numbered on top. Minimum new/default: video 1, video 2, audio 1. Max 12 tracks, 100 clips, 18000 frames. Empty timeline valid; render empty rejects.
- clips {id,trackId,assetId,name,startFrame,durationFrames,sourceInFrame,rect:{x,y,width,height},gain:1}. All time/frame fields integers. rect in output pixels; defaults {x:0,y:0,width:720,height:1280}; positive even width/height 2..output, nonnegative even x/y, rectangle bounded output. Image sourceInFrame=0; media source bounds validated. Immutable asset refs+hash snapshot; no implicit follow current shot version. gain 0..2.
- Same-track intersecting clips rejected, touching edges allowed. Video tracks image/video; audio tracks audio only (audio/mpeg, audio/wav, audio/mp4). Hidden is picture-only, muted silences all track sound, video embedded audio mixed if unmuted. Audio hidden unsupported. Visual fit contain inside rect with transparent padding; black background for gaps. Standard stereo48kHz AAC and H26430fps720x1280 output. No transitions/stretch/rate effects.
- timeline.get {projectId}. Additively ensure one empty default timeline on old projects, never auto-copy shots. Explicit seed-from-shots allowed only empty clips. Simple export.create unchanged sequence behavior.
- timeline.track.add {projectId,expectedRevision,requestId,kind,name?}
- timeline.track.update {projectId,expectedRevision,requestId,trackId,patch:{name?,hidden?,muted?}}
- timeline.clip.add {projectId,expectedRevision,requestId,trackId,assetId,name?,startFrame,durationFrames,sourceInFrame?:0,rect?,gain?}
- timeline.clip.update {projectId,expectedRevision,requestId,clipId,patch:{trackId?,name?,startFrame?,durationFrames?,sourceInFrame?,rect?,gain?}}
- timeline.clip.remove {projectId,expectedRevision,requestId,clipId}
- timeline.seed {projectId,expectedRevision,requestId} copies selected shot versions in order to first video track ONLY if no clips; frozen refs, refuses missing selections.
- All timeline mutations return entire updated timeline; idempotency must return exact saved response for original request even after future edits; request conflicts check before revision. Revision increments once per applied mutation. Read migration does not increment project revision.
- timeline.render {projectId,expectedRevision,requestId,purpose:'preview'|'export'} returns existing exports table job with mode:'timeline',purpose,timelineRevision,snapshot:{timeline,assets:[{id,sha256,...metadata}]}, status,assetId,url. Snapshot is immutable, output reused only if exact matching snapshot possible, never overwritten. Actual render preview and export identical semantics; stale status determined by current timeline revision. Worker safe source path+hash verification like existing export. On restart queued/running render recovery same as exports.
- UI drag payload application/x-workbench-asset asset ID (plus plain text fallback as needed). Frame conversion round(seconds*30), timeline drop x maps to frame; clip move preserves duration/source. Frame precision inspector numeric fields available; render button + seekable actual video, stale label after edits. Canvas and sequence retain behavior.
