## 宣称 Mac 桌面试用可用前还需工程验收

下面不是要求使用者自行诊断的清单。由验收人员在相同源码、同一架构的 Mac 上补齐：

- 核实实际 utilityProcess 的 Node/SQLite 版本、沙箱、权限拒绝和私有 discovery 文件
- 使用隔离试用项目检查本地 FFmpeg 导出进行中的正常退出、再次启动后的渲染恢复；确认直接持有的后端/媒体进程确实退出，且没有重复发布。这里的实际导出不涉及真实 AI 供应商
- 对二十一类持久本地编辑（原十二类加波纹删除、主体创建/追加版本/镜头关联、时间线输出规格、字幕新增/更新/移除及完整固定倍率候选原子应用）的代表性恢复场景，记录原请求编号、完整参数及账本/领域回执；重建应用后发现同一请求，启动/列表读取不执行编辑，明确恢复后只产生一次业务变更。完整边界按 [TASK-RECOVERY.md](TASK-RECOVERY.md) 验收，不能把生成/导出等会话参数宣称为全面持久恢复
- 检查仍存活旧会话的明确转存不执行编辑；已丢失旧会话不推测重建，未确认结果不以新编号重提
- 验证 Application Support 的实际路径、原生 Save As、播放解码和单实例行为；production/development 使用不同新目录，跨渠道复用合成目录应无损拒绝，保留 marker 和业务文件哈希。两渠道共用 staging，不能并行构建
- 验证旧数据/不安全目录遭拒绝时数据保持原样；不自动迁移、修权限、删除凭据或绕过 macOS 安全阻止。测试只使用合成副本，保留原数据
- 将本次 Mac 结果与精确源码清单和生成的构建文件哈希绑定

既有 `apps/desktop/scripts/smoke.mjs` 使用临时目录、预置项目和故障注入，不能不加核对地充当上述 Mac UI 导入验收；Mac 临时目录可能有被隐私策略拒绝的路径别名。只有明确安排的隔离工程故障测试才执行对应步骤。

如果只完成浏览器入口，上述 Electron 桌面项保持未做。隐私存储拒绝不能靠浏览器入口绕过。Agent 与官方/自定义 Images 专用设置及安全存储接入已实现；Keychain 真实持久化、异步 safeStorage 候选、强杀孤儿进程恢复、双架构安装包、签名、公证、升级和 Windows 仍是独立验收范围。9e基线使用同步 safeStorage；本次macOS异步候选另列版本/构建和原生验收，不把合成通过当作Keychain授权/退出保证，Linux仍保留原同步限制；Windows ACL 后端仍阻止正常启动。本文不将这些项目记为已通过。
