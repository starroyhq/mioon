## 用户行为

用户明确从项目菜单打开项目、创建后打开项目或使用页面历史切换项目，只有该项目实际载入成功且仍属于本次选择，才记住下次打开的位置。同一项目的再次明确选择也可记录；网络失败、旧响应、取消切换、卸载后的结果不会被当成成功。

启动选择顺序为：有效的显式 `?project=` 链接、当前工作区有效的最近项目记录、原有项目列表首项。指定项目或记住的项目缺失会说明回退；没有项目则保留原有新建流程。启动读取和自动显示本身不写最近项目记录，也不会自动发送业务编辑、模型请求或审批。

项目打开后继续复用已有的工作区视图偏好，包括画板/剪辑模式、选择、播放头、缩放与面板位置。位置记忆和已保存项目、片段本地草稿是不同存储。未确认的最后一次选择可能在崩溃后丢失；顶部显示位置保存状态，详情中可核对问题。不会承诺突然断电或每次点击绝对零丢失。

恢复分支保留既有本地查看、编辑和导出，明确显示本片最近项目记忆不启用，不读取或写入原工作区定位文件。

## 固定私有存储

普通工作区使用固定旁文件 `last-project-v1.json`，最多4KiB，仅存格式版本、后端计算的工作区作用域、独立revision、projectId和更新时间。没有名称、提示词、认证配置、令牌、媒体或任意路径。项目身份仍是本地用户数据；文件沿用私有权限和有界原子写入策略。

作用域由可信渠道、实际私有工作区路径/目录身份和SQLite文件身份共同计算，不由renderer或HTTP参数建立。复用现有独占工作区锁，同步调用串行CAS；不是新分布式锁，也不宣称隔离同一系统用户的恶意进程或消除路径式存储的全部TOCTOU。

GET不创建文件。损坏UTF-8/JSON、未知格式、不安全权限、symlink、其他工作区记录或不可读文件使定位功能失败关闭，不静默清空。初次发现外来定位文件尚未建立任何定位身份，普通项目仍可手动打开且不用浏览器缓存；重新加载页面不会修复或删除该文件。若先前已验证的服务/工作区身份在同一renderer中变化，则停止启动恢复并要求重新打开页面。PUT检查已存在项目和当前作用域/服务实例，再按独立revision写入，并确认父目录持久化。项目身份读取通过主键查询、至多16KiB的关系行JSON核对，不返回项目正文。

原业务SQLite格式和历史、任务、版本、回执不变。既有离线工作区备份不包含此旁文件；不能声称备份能恢复最近项目位置。旧 `mioon.project` 浏览器槽不删除，但新启动流程不把它当跨工作区或桌面生命周期的身份依据。

## 请求、冲突与旧响应

- 已认证的专用 `GET /api/last-project` 和 `PUT /api/last-project`，无查询参数；复用现有Host/Origin与身份检查，不加入RPC、CLI/MCP或内置Agent工具目录。
- 严格PUT字段为 `workspaceScope`、`instanceId`、`expectedRevision`、`projectId`。请求体和URL各最多2KiB，响应读取最多4KiB；客户端默认整个请求/响应5秒期限，超时不是确定未写入。
- 最新一次相同projectId与原expectedRevision可精确重放确认，不增加revision；其他陈旧写入409冲突。重放前仍核作用域、服务实例和项目存在性。这个有界位置投影不是业务任务台账，不提供任意历史回执重放。
- renderer串行发送明确选择，保留原未知输入；不会在GET、重新联网或较新选择后自动变更旧请求的CAS值重交。显式同一次重试只对仍匹配的当前选择开放。只读核对包括空结果都不撤销未知写入，也不自动恢复队列。
- 两窗口竞争时一个CAS胜出，另一窗口保留冲突提示。改变服务实例或工作区身份后停止写入；需要重新打开页面。晚到读或写回应不能恢复旧窗口权限、改变已打开项目或降级较新成功状态。
- 原生关闭的已有有限视图保存等待同时观察位置队列；不能确认时仍由原关闭提示处理，不伪称已经记住。
