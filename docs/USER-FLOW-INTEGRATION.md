## 本轮范围

- Mock 缺少 drawtext 时显示具体原因；读取能力失败或未知不当成确认缺失。缓存只保留一个明确配置的可执行文件身份，路径、文件或 PATH 变化会失效。
- 子进程退出未确认与取消优先保留，不能被能力说明覆盖。只有 Mock 在下载阶段确认 `MOCK_RENDERER_UNSUPPORTED` 才转为失败；原请求保留，需要用户明确重试才创建新任务。
- 保留用户的 Inspector 保存/生成提示、空时间线建立提示、选中返回属性、素材来源版本提示与显式替换入口。
- 选择镜头/片段时显示正确的属性子页；等待放弃草稿期间，新的页签选择、项目/目标/时间线变化不能被旧回调覆盖。已发出的草稿 DELETE 不声称撤销。

来源版本提示依赖正常业务产生的受信项目快照。合法生成流程为版本建立独立素材，时间线保持固定来源；没有证明正常业务能产生重复且矛盾的反查候选。坏快照中的重复 assetId 或相互矛盾的显式来源仍是提示层的防御限制，本轮没有新增通用来源模型，也不会据提示自动替换素材。
