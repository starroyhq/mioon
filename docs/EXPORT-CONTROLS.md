# 导出进度、取消与文件操作

导出弹窗依次提供检查、设置、确认、进行中和完成。只有明确开始导出才会创建成片任务；关闭弹窗或“在后台继续”只关闭观察界面，任务继续执行

进度显示真实阶段和耗时。编码器没有可测百分比时显示不确定进度，不使用估算的百分比。CRF 文件大小须编码后确定，用时取决于设备和内容

“取消导出”需要确认，只停止当前本机导出及其所属媒体子进程，不影响源素材或已有成片。取消保留原始导出记录和请求身份；已写入项目的文件保留，未完成的文件不会登记为可用输出。历史记录仍使用原有 `failed` 终态，以 `EXPORT_CANCELLED` 区分取消，界面显示“已取消导出”

完成页提供实际规格、大小、保存路径，以及打开、定位、复制路径、导出记录和再次导出。浏览器通过媒体链接打开文件，并显示和复制服务器路径；桌面应用使用受限本机入口，重新核对项目、导出、文件所有权和内容后才打开或定位文件

| 公共操作 | 范围 |
| --- | --- |
| `export.activity.get` | 读取一个导出的阶段、实际耗时和可用进度；不可测进度为 `null` |
| `export.cancel` | 取消指定项目中的单个已接受导出，重复调用不会重新渲染 |
| `export.output.get` | 校验已完成输出的发布来源，返回 `fileLocation`、大小、SHA-256、发布证明和媒体地址 |

三种传输共享严格的 `projectId` / `exportId` UUID 参数与权限检查。公共接口不接受任意路径；恢复或候选工作区保持各自原有的文件操作限制

成片写入项目目录的固定 `导出/`，目录名不随界面语言变化。输出必须同时符合导出回执、资产、完整 SHA-256 和发布证明；同目录或同字节的其他文件不能冒充输出，重新指向项目外文件也不能获得导出权限。此专用输出描述将发布位置投影为 `publication.projectRelativePath`，普通资产结果仍隐藏路径。桌面在 POSIX 和 Windows 上都使用真实文件句柄核验完整内容、大小和身份，在打开或定位前再次核对当前窗口及后端描述。

恢复只补回已经登记但缺失的成片，上传字节必须与冻结的完整哈希和大小一致。恢复使用私有暂存和原目标的排他发布；目标重新出现时不覆盖，不修改原导出、资产或快照记录。项目中的失败发布残留不会自动删除；复制项目时若未带上本机暂存回执，这些文件可能显示为未引用媒体，但不会自动登记为成功输出。

任务编码完成后，先在本机私有暂存目录持久化完整产物清单，绑定冻结请求、资产 ID、发布 ID、完整哈希和媒体规格；浮点检查导出同时保存已经验证的音频报告。重启后的既有任务可按完整清单继续本地发布，无需再次编码。缺失、损坏或归属不符的清单不能靠现存文件冒充成功；失败发布保留完整暂存，正常登记后只清理对应的私有媒体暂存。
