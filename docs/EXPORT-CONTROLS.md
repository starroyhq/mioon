# 导出进度、取消与文件操作

导出弹窗依次提供检查、设置、确认、进行中和完成。只有明确开始导出才会创建成片任务；关闭弹窗或“在后台继续”只关闭观察界面，任务继续执行

进度显示真实阶段和耗时。编码器没有可测百分比时显示不确定进度，不使用估算的百分比。CRF 文件大小须编码后确定，用时取决于设备和内容

“取消导出”需要确认，只停止当前本机导出及其所属媒体子进程，不影响源素材或已有成片。取消保留原始导出记录和请求身份，不发布部分输出。历史记录仍使用原有 `failed` 终态，以 `EXPORT_CANCELLED` 区分取消，界面显示“已取消导出”

完成页提供实际规格、大小、保存路径，以及打开、定位、复制路径、导出记录和再次导出。浏览器通过媒体链接打开文件，并显示和复制服务器路径；桌面应用使用受限本机入口，重新核对项目、导出、文件所有权和内容后才打开或定位文件

| 公共操作 | 范围 |
| --- | --- |
| `export.activity.get` | 读取一个导出的阶段、实际耗时和可用进度；不可测进度为 `null` |
| `export.cancel` | 取消指定项目中的单个已接受导出，重复调用不会重新渲染 |
| `export.output.get` | 校验已完成的独占托管输出，返回 `fileLocation`、大小、SHA-256 和媒体地址 |

三种传输共享严格的 `projectId` / `exportId` UUID 参数与权限检查。公共接口不接受任意路径；恢复或候选工作区保持各自原有的文件操作限制
