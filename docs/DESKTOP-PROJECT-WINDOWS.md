# 桌面独立项目入口与编辑窗口

基线：`0eb0cb8ae6a2a3a58878bfdceea5af52b935ec75`。本片父级第二轮完整门已通过；首轮全量失败与精确测试适配证据均保留。正式 typecheck、定向测试、最终生产包检查和 Linux 原生验收已完成。历史 [H1](PROJECT-HOME-H1.md) 与 [P0](NATIVE-CLOSE-ADMISSION.md) 的数字不充当本片通过结果。

## 本片范围

- 一个项目入口窗口、最多一个编辑窗口、一个共享 backend。入口复用独立项目首页，编辑器保留用户的工作台布局。Web 仍是原单页，不增加窗口 API。
- 首次入口使用原有效 URL → 工作区定位 → 项目列表首项优先级；入口重新显示/重建不再自动打开刚关闭项目。原定位记录、项目业务记录、旁文件均不因关闭或显示首页删除。自动恢复本身不写定位；用户明确打开/新建后，只有编辑器数据与设置真正就绪、原生文档/后端/项目/意图版本仍匹配，才调用既有定位写入。打开失败、重载、退出和迟到回应不能借用旧打开意图。
- 已有编辑器时重复打开同项目只聚焦；另一个项目明确拒绝，先处理并关闭当前编辑器。原编辑器内项目切换/创建仍沿既有业务与草稿守卫，不新增提交权限。
- 只有收到真正 `closed` 事件才释放窗口位置；隐藏或 destroyed 状态不能冒充已安全关闭。已接受生成/导出不因关闭编辑器取消；backend 与任务生命周期保持独立。
- 原生设置只在入口窗口显示，四个配置槽仍用原设置组件。编辑器进入设置前同步失效 Agent/Images 的旧交互许可；返回后保留普通草稿，需重新明确确认。已有隐藏清密钥、dirty/busy/unknown 设置规则继续生效。

## 固定桥与权限

[协议](../apps/desktop/src/project-window-protocol.ts)、[preload](../apps/desktop/src/preload.ts) 与 [窗口主机](../apps/desktop/src/project-window-host.ts) 仅传递固定动作、UUID 与非秘密身份；不接受任意 URL、路径、脚本、业务 RPC、密钥或原生文件操作。每次请求绑定当前窗口、主 frame、当前 URL、backend 与文档 context。导航会轮换 context；旧窗口、旧 frame、旧文档结果不能控制替代窗口。

浏览器 sandbox、contextIsolation、webSecurity、无 Node、权限拒绝、同源 cookie 与媒体下载身份验证继续保留。下载只允许当前编辑器及其当前 backend 的已验证成片；入口不能借用编辑器下载权限。preload 是独立打包的固定 CJS 文件，包检查精确验证其存在、允许名称与构建字节。它不是通用 IPC 插件接口。

## 关闭、重载、退出、恢复

- 显示首页不卸载编辑器，不重建其 App/controller owner。正常编辑器关闭复用 P0：先捕获所有受保护输入与身份，按原流程 drain，再在实际关闭前只读复核。程序化新输入、业务 busy、未知结果或 owner 变化都不能被旧确认放行。
- 片段、镜头文字、成片草稿提供只读关闭快照；隐含保留的 intent/deletion/prepare owner 仍阻止普通关闭。导出设置/范围内存输入另行计入 dirty。普通已接受任务不因此阻止关闭。
- 旧素材导入、项目新建和部分旁文件 DELETE 没有精确跨重启对账协议。导入/新建响应未知保留窗口内非秘密操作身份，不能把 inflight=false、刷新列表或 toast 当 ACK。普通关闭默认留窗；reload 也不能用风险许可越过未知结果。
- 对**非 busy、精确 owner/version/operation 未变**的未知记录，单独提供“了解风险并关闭”。说明操作可能已在后台完成、离开不等于失败或取消、重复导入可能生成重复素材。这与普通“放弃修改”是两个独立选择；取消保留全部线索。许可仅本次关闭一次消耗，不改成功状态、不删业务记录、不重发请求。仍有其他未保存输入时另需其原有确认。确认期间新输入、晚 ACK、新未知或换 owner 使许可失效。未提供“不再提醒”。
- 此显式风险出口不是自动对账。窗口关闭后仅内存的未知线索可能不可恢复；精确导入/新建/DELETE 恢复协议列为后续独立工作，不伪称已完成。
- 明确 Quit 先从 requesting 状态禁止创建/显示窗口，再逐窗使用 P0，真正全部关闭后才停服务。取消保留仍在的 owner 和后台。Restart 同样逐窗准入；重启中到来的 Quit 被保留并串行执行，不丢点击、不并发停启、不把一次许可跨 await 复用。
- Electron 确认 renderer gone 的恢复/退出保持 P0 单次 generation 证据规则；unresponsive 不等价 gone。恢复不保证已死亡 renderer 的未保存内存输入，不重提交任何业务。
