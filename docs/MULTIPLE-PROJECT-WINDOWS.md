本片按用户确认的窗口规则修正桌面版：

- 项目列表窗口单例，仅零个项目窗口时可见。有项目窗口时隐藏；最小化和切换焦点不等于关闭。
- 不同项目可各自打开一个编辑窗口；同一项目再次打开只聚焦原窗口。打开中、失败或关闭检查中的窗口仍占有自己的项目，不能借此新建重复窗口。
- 关闭最后一个实际项目窗口才显示列表，并按既有只读路径刷新列表；刷新不解除新建结果未知，也不自动打开项目。退出/重启请求期间不复活窗口。
- 各窗口共享一个工作区后台。关编辑窗口不取消已接受的生成、编辑或导出任务，也不停止其他项目。
- 编辑窗口和应用菜单提供“打开工作区项目”和“新建项目”入口。它们使用现有项目列表及创建服务，不是任意项目文件选择器。原编辑器及输入保持原项目归属。
- 连接设置使用独立单例窗口。表单和秘密输入不转移到调用窗口；窗口关闭、重载和设置页切换沿用既有精确准入规则。
- 普通 Web 路径仍为单页，保留原项目切换与 URL/最近项目选择行为。

## 输入与生命周期

每个 native editor 的项目和分配 URL 固定。原生同文档 history 变化只恢复本窗口固定 URL，不打开别的项目；跨项目操作走明确新窗口入口。普通项目 CRUD、稳定 requestId、审批与恢复权限不改变。

打开入口拥有自己的输入版本、窗口/文档 generation、单次 token 和精确回执。确认后新输入或 owner 变化会撤销本次许可；丢失窗口动作 ACK 时只核对原回执。新建项目业务结果未知不能被列表刷新、同名项目或窗口数量当成成功；不自动再次创建。

App 级原有草稿、busy、unknown owner 不因打开其他项目而清空。普通关闭、已知未知结果的单次风险选择、重载与 Electron 确认 renderer 已消失后的恢复，保留 [NATIVE-CLOSE-ADMISSION.md](NATIVE-CLOSE-ADMISSION.md) 的边界。恢复提示按窗口分别归属。仅从未提交任何文档且仍是同一空白 frame 的初始失败窗口可以使用原生空窗口证明重试固定 URL 或关闭；已载入的页面继续通过原 P0 准入。

全局最近项目位置仅由保留的 launcher 写入。各 editor 不独立写同一个 CAS 记录；它们只读显示状态。设置窗口可要求原 launcher 对账或重试同一保存体，不获得新的写入身份。后端停止会撤销新入场，仍保留旧输入的关闭检查；旧后台/窗口的迟到回调不能作用于替代 owner。

## 一个应用仅一份声音试听

只涉及已保存时间线的有界声音试听，不改变混音参数、导出字节或已接受的业务任务。

- A 试听期间，普通聚焦 B 不停止 A。B 明确点击准备时，先请求 A 停止并释放，再申请自己的试听。
- 必须同时证明 A 的 WebAudio/原准备请求结束、后台原 HTTP 响应结束和自有媒体子进程退出，才释放旧预算。超时或观察中止不是退休证明。
- B 等待时可以取消。A 的迟到 ACK、关闭、重载或旧 release 不能释放 B，也不能在 B 已取消后重新授予它。
- 后台重启前同样等待旧 epoch 退休。若 utility 已真实退出，只有同一 supervisor 的退出确认且无未确认媒体，才可补足后端半边证明；renderer 半边仍需真实退休或销毁。存在未确认媒体时保持失败关闭。
- 原 20 秒、96 MiB 总驻留预算、单 decoder 和 120 秒预算保持。没有新的持久缓存。进程内操作 ID 去重有界；单个文档达到 1024 次声音准备身份后需通过正常安全重载再使用，不驱逐旧 ID 后把重放误当新动作。

固定 PCM HTTP 请求必须来自持有当前 lease 的真实主 frame。main 以本进程临时 Ed25519 私钥签名固定路径、方法、完整规范化查询、epoch/lease 和一次序号；公钥仅送到自己的 utility。私钥不落盘、不通过 preload/RPC/日志返回，不从可被外部客户端持有的会话 token 推导。

桌面后台上通过外接浏览器直接调用 PCM 会被明确拒绝；CLI/MCP 的只读试听 plan 仍可发现。独立 Web server 保留原 Web PCM 路径。此私有协议不能调用任意业务操作、URL、文件或付费接口。
