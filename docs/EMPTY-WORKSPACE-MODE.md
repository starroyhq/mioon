## 行为与边界

- 尚未打开项目时，画板/剪辑模式入口明确禁用；复用现有空画板段落提示“先创建或打开一个项目，即可使用画板和剪辑。”，保留原创建按钮。
- 空状态的模式组可通过键盘聚焦；模式组、模式按钮与创建按钮关联该可见说明。已有项目不增加额外模式组焦点，也不显示空状态说明。
