# 独立项目首页 H1：打开与展示边界

基线：`73bd7cc7d3595e0a2a4a912621b74c34571f1f0d`。对应 [首页分层规划](PROJECT-HOME-PLAN.zh-CN.md) 的 H1；H2 安全关闭项目/历史路由和 H3 跨流程总验收尚未完成。

## 本片范围

- 未打开项目时显示独立项目首页，列出当前工作区项目，提供页内新建、打开、读取中、项目错误与重试。不是可移植项目文件打开，也没有新增多项目 MRU。
- 保留既有启动选择顺序：有效显式 URL、已验证的稳定上次项目定位、项目列表首项。只有项目数据、偏好、工作区来源、当前打开 epoch 全部一致才挂载工作台。
- 打开后没有镜头仍是有效工作台，保留原画板/剪辑布局与添加镜头提示。首页不挂载空画板、项目属性、任务或生成面板。
- 连接/认证/工作区身份错误仍走原全局边界，普通项目读取失败留在首页解释原因。明确的恢复来源不符不能被降为普通项目错误。
- Agent、官方图像、兼容图像、本机 ComfyUI 设置可在首页页内查看。只读报告脏/忙/结果待核对状态及版本；没有表单字段或凭据进入导航注册表。进入项目或离开设置前，未保存输入须显式确认；忙或结果未知留在原页，取消保留表单。隐藏时按原规则清空新输入密钥。
- 设置返回按钮在首页明确写“返回项目列表”，旧工作台默认标签保持。查看、切换页签与返回不会自动保存、生成或检查 ComfyUI 服务。

## 生命周期与兼容

当前 App 级 durable/unknown、草稿、定位和偏好控制器仍由 App 持有。本片不重建持久化引擎，不改变业务回执、CAS、原请求 ID、项目保存或模型授权。项目级观察只有已确认打开的 session 才能启用；迟到数据、创建 ACK 和列表响应不能覆盖新项目、工作区或卸载后的生命周期。

新建采用原 `project.create`：新建已接受但列表读取失败时提示先刷新核对，不自动重新创建。完整新建流程有单次在途门，包括 ACK 后读取列表的窗口。项目首次读取仍沿用原服务（包含 `timeline.ensure`），不宣称打开项目绝对零数据库写入。

设置组件的可选报告与返回确认保持旧调用兼容，导航快照与 owner/version 绑定。表单卸载先退休报告，旧 ACK 和子组件清理不会重新注册一个已释放的设置实例。

H1 不提供“关闭项目”或“取消打开”按钮。回首页时如何安全 drain、保留不确定请求、处理 URL/后退/下次自动打开属于 H2；没有通过清空项目身份伪装已交付。
