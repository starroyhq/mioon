## 4. 核验完成与报告要求

技术成功需要同一个获准任务达到明确终态，保留供应商任务 ID，下载结果经过媒体探测及完整解码，核对精确来源、实际时长、宽高／比例、音轨，以及约定的本地导入／播放／剪辑／导出。供应商返回成功但下载或解码失败，不能报告完整流程已通过。

费用核验另行记录实际金额与币种。未结算／账单不可确认时写明“技术结果已核验，费用待确认”；失败或受理不明时说明是否仍可能计费及待调查事项，不能声称免费、免扣费或可退款。

报告仅限本次模型、区域、账户和素材。mock、注入 HTTP 契约与真实结果分列；一次成功不会自动批准再次调用、扩展供应商、改动 `liveVerified` 或发布视频。不要在报告中暴露密钥、授权头、完整签名下载 URL 或无关账户信息。
