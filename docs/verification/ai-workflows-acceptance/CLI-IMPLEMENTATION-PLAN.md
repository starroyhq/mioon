# 纯 CLI 助理闭环与三系统配置支持

来源：用户于 2026-10-21 明确要求实施的计划。本文记录审查基准，不代表实现或验收已经完成。

## 目标与边界

在当前 `codex/ai-workflows-acceptance` 分支保留已有改动，先打通 CLI 配置、诊断和任务控制，再验收真实模型回复、只读工具调用及自主剪片。

沿用现有 harness、网关和持久化机制。视频生成使用 Mock，不调用真实图像或视频付费接口，不 commit、push、部署或发布。

2026-10-21 用户追加确认：模型请求改用官方 `openai` SDK，允许新增必要依赖。锁定 `openai@7.39.0`，Chat Completions 和 Responses 均使用 SDK 的 `create`；自定义 fetch 仍通过现有 Mioon 网关。保留请求写库、发送前授权复查及有界 SSE/工具结果校验，关闭 SDK 隐式重试和日志，不从 SDK 环境变量继承凭据或服务地址。不以此引入另一套执行循环，也不默认开启样例中的深度思考。

## CLI 与任务控制

- 继续使用独立启动的 headless 服务，CLI 连接同一后端。无需启动 Electron，也不由 CLI 自动启动第二个服务。
- 新增独立 Agent 客户端与命令：配置 `agent settings get/set`、`agent settings secret set/remove`；策略 `agent policy get/set/lookup`；任务 `agent task status/history/send/lookup/upload/upload-lookup/watch`；控制 `pause/resume/stop/approve/deny/undo-change/undo-all/resolve-unknown/action-lookup`。
- 复用现有 `/api/agent/settings` 和 `/api/agent/tasks/v2`。管理命令不加入模型工具目录或 MCP 工具发现；现有业务 CLI、MCP 和授权命令保持原语义。
- 任务、策略及控制写操作使用调用者提供的稳定请求 ID 和版本。响应丢失后只查询原回执，不自动重发。配置 PUT 目前没有持久回执，丢失响应时读取现状并报告结果未知，不冒充保存成功。
- stdout 保持单个 JSON 信封，进度写 stderr。watch 通过 SSE 通知重新读取快照；断线只重连和查询。需要审批、恢复或未知结果处置时退出并返回状态；Ctrl+C 只停止本地等待。
- 审批继续绑定精确参数、步骤和版本；不增加全局自动批准开关。独立图像审阅入口保持现有边界。

## 跨重启密钥与 Windows 存储

- Key 通过隐藏终端输入、`--key-stdin` 或明确选择的私有文件提交，禁止明文命令参数。默认持久保存，也允许显式选择会话保存；沿用现有长度和字符校验。
- 锁定 `@napi-rs/keyring@2.1.2`，通过有超时限制的辅助进程调用。系统凭据库只保存随机加密密钥，API Key 使用 AES-256-GCM 保存于现有私有配置中，绑定工作区、渠道和模型配置。
- 已有加密密钥不自动覆盖或轮换。先确认凭据库可用，再原子提交配置；失败保留旧配置。Linux 明确使用 Secret Service；不可用时阻断持久保存，不静默退回明文或会话模式。桌面已有密钥不自动迁移或抽取。
- Windows 新增完整的 Node-API 私有存储后端：覆盖安全创建、SID/ACL 校验、完整文件身份、有界读取、原子替换、不覆盖发布和删除。操作绑定已验证句柄，拒绝重解析点、硬链和不安全路径，已有权限只检查、不修复。
- Windows 首版限定本地固定 NTFS。共享存储接口改为调用时分派，由服务端、CLI、MCP 和离线备份入口统一初始化；缺少原生模块或验证能力时继续拒绝。此次不扩展 Windows 桌面打包和发行认证。

## 诊断与真实验收

- agent doctor 默认不调用模型，检查连接、配置、凭据状态、授权和工具 schema。agent diagnose --live 明确执行真实诊断，支持纯文本、只读工具和完整目录检查；缩减工具目录仅用于定位问题。
- 诊断请求仍经过正常授权、网关和写库流程。诊断类型及工具范围持久保存，不能扩大权限；完整目录诊断不执行业务写操作。
- 定位当前供应商拒绝工具 schema 的根因，修复模型协议投影，同时保留领域校验和权限限制。最终验收使用完整准入工具目录，缩减目录成功不计入完整验收。
- 在独立测试工作区依次完成真实模型普通回复；真实模型调用只读工具、接收结果并继续回复；真实模型自主使用工具完成剪片：两段本地素材加一段 Mock 生成视频，组成约 6 秒时间线，加入两条中文字幕和背景音，导出可播放的 H.264/AAC 成片。
- 剪片由 Mioon 内置模型规划和调用工具；外部脚本只准备素材、提交任务、观察及核验结果。检查实际时间线、生成记录和成片画面、字幕、音频，不能只依据模型文字判定成功。
- 默认每轮 30 步，必要时继续原 Run。失败后先查明原因并修复，不通过新建请求重复提交生成。真实 Key 若不可用，再通过安全输入保存，绝不从桌面进程提取。
