## 本轮修改

- 补齐设置导航图标、语言/数字格式说明、底部保存栏；长备份技术说明默认折叠，已有核对/恢复动作保持可达

- 修复版本缩略图的旧样式尺寸覆盖，V1/V2与两张卡可读；版本对比完整显示竖屏画面
- 助理消息独立滚动，目标摘要/输入固定在底部；待审阅差异、批准/拒绝和长地址不再遮挡
- 任务中心改为左列表/右详情；未知任务可直达对应对账。增加只筛选已加载数据的搜索与四类状态筛选，隐藏详情及旧回调继续受可见性/生命周期约束
- 导出标题/标签对齐，已接受的旧请求详情和音频技术信息折叠，确认摘要两列，完成页显示保存结果、名称及冻结规格

## 环境阻塞与未通过项

1. **FFmpeg缺少drawtext/subtitles**：本机FFmpeg9.0.2的libx264/aac可用，正常无字幕合成/导出已完成。`version-comparison-media.test.mjs`的真实Mock发布测试在worker准备阶段以`MOCK_RENDERER_UNSUPPORTED`失败，未进入该项HTTP断言；12项中11通过1失败。详情见[独立诊断](tests/version-comparison-media-environment.md)。版本界面采用明确的DB/service媒体夹具，不能替代生成成功发布链路；带这些滤镜的生成/字幕导出仍需具备能力的环境复验
2. **原生交通灯颜色/点击点未完整验证**：系统`screencapture -l`对普通应用窗口返回`could not create image from window`，改用绑定原生应用的截图可得到完整Mioon窗口。系统录屏/控制指示层覆盖交通灯区域，未将激活颜色与点击点标为通过；实际项目窗口启动、布局和渲染已验证

## 有意保留的设计适配

- 真实生成总开关反映后端启动配置，界面只读；不为了视觉稿新建设置写入接口
- 工作区使用已有离线备份和数据库核对流程；设计中的自动备份/一键文件备份恢复未有对应后端能力，不提供无法执行的占位控件
- 任务和导出复用现有安全动作；生成中的停止等待在任务中心可达。未增加设计中会改变历史/任务业务含义的清已完成、标记失败或新的导出取消操作；ID以原值可读，缺少专用复制按钮不视为明显布局阻断
- 导出设置包含现有完整音频/范围能力，因此使用内部滚动；确认页保留真实检查结果及警告，进行中显示实际百分比，不伪造设计样例阶段
- 四语言矩阵覆盖通用设置、导出检查与紧凑助理；36页主状态为简体中文深色。没有把40张补验描述为全部36页×四语言×两主题×两尺寸的穷举

本轮未提交、推送、发布或调用真实供应商。临时数据为自产几何媒体与测试文本；私有设计源和导出图保留在本地忽略目录
