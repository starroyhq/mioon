## 证据边界

- 本次只读截图复核，不修改源码，不操作浏览器。主验收的实际交互结果另注明来源；没有将读图描述冒充本代理执行的交互。最终functional-final.json的pageErrors为空，没有把共享采集器中过去的面板尺寸错误记录为本轮新异常
- 版本媒体为本地合成MP4的明确fixture，证明版本页及对比页可呈现真实媒体；不代表供应商生成成功。生成中及未知结果来自本地mock状态，没有调用真实供应商
- 当前FFmpeg缺少drawtext；后续Mock发布会进入MOCK_RENDERER_UNSUPPORTED，详见[独立环境记录](tests/version-comparison-media-environment.md)。生成中截图只证明真实本地任务在处理中，不代表生成成功
- 主验收已确认任务中心既有“停止等待”入口可达。画板底栏仍未设置设计中的单页直接取消按钮；不把停止等待扩大为已撤回供应商请求，也不伪造直接取消入口
- 这8张为1440×900、简体中文、深色主题；1050×680、浅色、其它语言、键盘与关闭/重开行为由其它专项记录覆盖。截图中未展示的展开状态或入口，不以“没有视觉异常”替代验收
