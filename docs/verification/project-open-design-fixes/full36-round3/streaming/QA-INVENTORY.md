# 本地 SSE 的 Chrome 归因核对

- 使用独立 Chrome 上下文，以正常登录控件进入本地工作台；令牌仅工具内读取并填写，不输出或记录
- 阻断浏览器所有非 127.0.0.1 网络请求；模型目标仅既有 127.0.0.1:57738 本地合成 SSE，复用已有 typed_chat_only 授权，不调用真实模型
- 打开指定合成项目与智能助理，发送一句可辨识的合成验收消息且不重试，记录实际发送次数
- 观察实时回复、完成/断开状态及页面错误，截图可见结果
- 如有断流，用界面显式重读记录对比持久结果，不能自动重新发送；如无断流，记录与 IAB 的差异及其证据范围
- 额外检查初次空输入禁用发送、请求结束后控件恢复；不改变业务代码、服务或授权范围
- 结束后关闭该 Chrome 上下文与浏览器
