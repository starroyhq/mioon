# 单片段响度补全验证清单

- 目标初始值只在本地；打开/切选/重开不触发分析
- LUFS/真峰值/LRA 来自完整同一片段；不足3秒不编造范围
- 修改目标使旧结果失效；空值、非法值与IME不提交分析或保存
- 有效候选实际复测通过后匹配进入草稿，未点击保存前时间线不变
- 原保存操作生效，重启/撤销/重做保持精确gain、一次历史
- 增益超过2、峰值冲突、重新门控目标失配不可匹配，不静默更改目标
- 隐藏、切项目、草稿冲突、未知结果、恢复候选令旧回调无效
- 1440×900与1050×680，中文/英文、深色/浅色代表状态，检查LRA与目标区可读、主操作不重叠
- HTTP、CLI、官方MCP统一解析显式target，仍为只读；历史无target响应与旧备份分类器保持
- 独立FFmpeg LRA对照、真实候选/保存后重测对照；不调用真实供应商
