## 2. 行为

**何时显示。**
- 只标新落库的 Mio 变化。会话按变化 id 和这一轮上一版快照比对，App 再按 id 去重：每条变化最多出现一次。
- 撤销产生的回退、superseded、之后又被用户修改（`modifiedAfter`）的变化不标；已经显示的标记在这些情况下立即结束。用户自己的修改不产生 Mio 变化记录，所以不会出现标记。
- 只在目标当前可见时显示。可见用命中测试判断：目标的一部分在画布或时间线的滚动区域内，并且是该点最上层的元素（没有被浮动面板、吸顶的轨道头和标尺、对话框盖住）。不可见时不切换模式、不滚动。
- 标记只取最具体的目标：片段的修改同时带上它所在的轨道（`task-tools-v2.ts:104`），不会因此点亮整条轨道；只有改轨道本身时才标轨道头。
- 每条变化一个标签，挂在它第一个可见目标上；同一目标再次被改时重新计时，只保留一个标签，并指向最新的变化。
- 切换项目、切换模式、卸载时清理所有标记、计时器和还没执行的显示。

**样式。**
- 外圈柔光加 1px 外环，取强调色：深色主题下是白色（与 07-01、07-02 一致），浅色主题下强调色是深灰，柔光随之变深，避免白光在浅底上看不见。
- 柔光是目标元素自己的 `box-shadow`，不另加覆盖层，所以不拦截点击、拖动和选中。选中描边（片段的 2px 实线边框、节点的强调色描边）保持不变，两者同时出现时都能辨认。
- 标签用共享按钮组件，收成设计的 18px 胶囊：sparkles 图标 11px、文字 10px 字重 600；点击区经 `::after` 扩到 24px。位置按设计：画布节点在右上角上方，片段在右下角内侧。
- 标签定位到目标**可见部分**：超出窗口的长片段、一部分被浮层盖住的节点，标签仍落在可见处；可见部分窄到放不下标签时，标签不显示，只保留柔光。
- 约 4 秒后用 0.4 秒淡出。鼠标悬停或键盘聚焦标签时保持显示，离开后 1.5 秒再淡出。系统开启"减少动态效果"时没有淡入淡出和平滑滚动。

**点击标签。** 切到 Mio 页签（右侧收起时用浮层打开），滚到对应的变化行、聚焦它的"定位"按钮并高亮 1.6 秒。不改变选中状态，也不改变属性面板显示的对象。标签可用 Tab 聚焦，带 `aria-label`（"Mio 修改，查看这处变化"），出现时不抢焦点。

**定位。** 保留原有的切换模式、在画布上 fitView、滚动时间线；定位后显示同一个标记，替换原来 3 秒的 `agent-ai-highlight`。
