# 第二版浅色候选

首版被用户指出“像是高对比”。本轮仅调整 `packages/ui/src/styles/light-preview.css`。第二版随后也被指出仍不理想，已由[参考Codex的第三版](../light-v3/README.md)继续修正；本目录保留历史证据，未被用户接受。

第二版采用浅暖灰窗口、近白面板和白色表单，依靠底色层次区分区域。面板边界、控件描边及轨道网格减弱；主操作与焦点保持中性石墨灰。媒体颜色保留原语义，深底片段及缩略图标签使用清晰白字，避免浅色文字继承落在深色媒体底上。

- 剪辑：[1440×900](editing-1440.png)、[1050×680](editing-1050.png)。
- 对比：[首版设置](../screenshots/light-candidate-settings-1440.png)、[首版剪辑](../screenshots/light-candidate-editing-1440.png)。首版作为被拒绝的历史候选保留。

使用重新构建的开发包，只临时启用候选类，没有注入替代样式。两尺寸四个页面状态无溢出，真实键盘焦点可见；浅色系统下 `system` 仍为正式深色，移除候选类后恢复相同深色。没有外部请求或真实模型调用。

token 检查5/5、typecheck和开发构建均通过；[浏览器结果](results.json)、[对比度](contrast.json)、[验证与初次脚本失败说明](verification.json)保存实际范围。没有把候选重拍视为用户已经确认，也没有扩展为全部浅色页面验收。
