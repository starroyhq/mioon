# 正式浅色与跟随系统

2026-10-19，用户明确确认：“第三版通过，启用浅色及跟随系统”。本轮正式启用 `dark | light | system`；默认仍为深色，已有 v1 偏好无需迁移。第三版的白色内容、近白侧栏、中性浅灰壳层和独立媒体遮罩进入生产样式。

Provider 统一管理互斥主题类、`color-scheme` 和解析后的 ReactFlow 主题。跟随系统实时响应外观变化，显式深色或浅色保持固定；草稿可预览，放弃恢复已保存选择。切换系统外观不写偏好。

保存成功后只广播 revision 提示，其他窗口从原接口重读。脏草稿及结果未明请求会延后同步，保留原 CAS 基线；导航回执也遵守相同保护。窗口 focus 提供只读刷新兜底，卸载清理频道和监听器。原生窗口从受限的私有 sidecar 读取已保存主题，更新空白边缘背景；不强制修改 `nativeTheme.themeSource`，保证系统外观查询真实。
