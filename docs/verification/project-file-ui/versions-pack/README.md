# 第 3 组：项目菜单、版本历史、恢复前确认、打包

组件：
- `ProjectFileMenuItems`、`ProjectFileMenu`（`ProjectFileMenu.tsx`）：12-07。`ProjectFileMenuItems` 只渲染菜单项，放进调用方自己的 `DropdownMenuContent`；`ProjectFileMenu` 是顶栏的项目名按钮加上这份菜单；
- `VersionHistoryDialog`、`versionTitle`：12-08；
- `RestoreVersionDialog`：12-09；
- `PackProjectDialog`、`PackCompleteDialog`（`PackProjectDialog.tsx`）：12-10、12-11；
- `shortcutLabel`（`format.ts`）：菜单里的快捷键。

几处共同的差异，表里不再逐行写：
- 截图里没有工作台。预览里菜单和对话框背后是剪辑页，这里是空的深色背景。
- 12-07 的菜单开着，但没有鼠标停在某一项上，所以没有预览里“版本历史…”那一行的高亮。
- 对话框打开时如果是按钮带着焦点，截图前在标题上点一下鼠标，所以不显示焦点框。
- 工作台的等宽字体 JetBrains Mono 这台 Mac 上没有装，快捷键、路径和大小用的是浏览器自带的等宽字体。

## 不适用的状态
- `PackCompleteDialog` 没有加载中、出错和空：打包完成才打开它。没有缺失素材的情况见 12-11-all-copied。
- `RestoreVersionDialog` 的“空”是这段时间里没有手动改动（12-09-empty）。
- `ProjectFileMenuItems` 的加载中、出错和空只出现在“最近项目”子菜单里，其余条目由回调决定显示与否。
