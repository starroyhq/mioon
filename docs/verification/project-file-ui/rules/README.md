# 第 4 组：项目规范、规范未启用的提示、规范修改的确认卡

截图 19 张，都是 PNG，共 364 KB（372,944 字节，`results.json` 里 `bytes` 的和），最大一张 33,081 字节。每种状态只截一张简体中文，另外三种语言由 CI 的渲染测试覆盖。

组件（都在 `ProjectRules.tsx`）：
- `ProjectRulesDialog`：12-12，参照项目说明（`ProjectNotesDialog`）的写法，做成受控组件；
- `ProjectRulesNotice`：12-13，Mio 面板里的提醒卡；
- `ProjectRulesChangeCard`：12-14，Mio 要改规范时的确认卡；
- `rulesBytes`、`rulesProblem`：字节数和不能保存的原因。控制字符的规则和项目说明一样，上限由 `maxBytes` 给（R2 定，画廊用 8192）。

几处共同的差异，表里不再逐行写：
- Mio 的对话和周围的工作台不在截图里。12-14 的对话本身不归 U1，U1 只做那张确认卡；12-13、12-14 截的是卡片，放在 300px 宽的外框里，背景比 Mio 面板深一点。
- 对话框打开时如果是按钮带着焦点，截图前在标题上点一下鼠标，所以不显示焦点框；12-12 打开时聚焦的是文本框，和预览一样带白框。

## 不适用的状态
- `ProjectRulesNotice` 没有加载中和空：只有规范未启用时才显示；启用中和启用失败见 12-13-enabling、12-13-error。
- `ProjectRulesChangeCard` 没有加载中和空：Mio 提出修改时才有这张卡；提交中、提交失败见 12-14-submitting、12-14-error。
