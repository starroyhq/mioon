# 第 2 组：素材状态、重新指向、项目外位置的确认

截图 18 张，都是 PNG，共 314 KB（321,262 字节，`results.json` 里 `bytes` 的和），最大一张 32,204 字节。每种状态只截一张简体中文，另外三种语言由 CI 的渲染测试覆盖。

组件：
- `mediaStatusDisplay`（`media-status.ts`）：把 L1 的素材状态换成界面上的状态，含 11-01 代定的两种待确认状态；
- `MediaStatusBadge`、`MediaStatusNote`、`MediaAttentionBanner`、`mediaStatusTone`（`MediaStatus.tsx`）：12-04；
- `MediaRelinkDialog`：12-05；
- `OutsideLocationsDialog`：12-06。

几处共同的差异，表里不再逐行写：
- 12-04 截图里只有 U1 的部分：素材卡片角上的标签、卡片下面的一行说明、素材库上方的提示条。卡片本身（缩略图、左上角的类型图标、时长、选中框）属于现有的素材库，截图里用一个简单的卡片代替，只为显示标签放在哪里；卡片边框和名称的颜色由 `mediaStatusTone` 给出。
- 12-04 时间线片段上的“缺失”“已变化”字样属于现有的时间线页面，不在 U1。U2、S6 接线时用 `mediaStatusDisplay` 和 `MediaStatusBadge` 加上。
- 12-05 的对话框背后没有工作台；12-06 背后是 U1 的首页组件。
- 对话框打开时如果是按钮带着焦点，截图前在标题上点一下鼠标，所以不显示焦点框。

## 两种待确认状态（11-01 代定，文案 S6 可以改）
项目外、还没确认的素材，照 L1 给的两种状态显示：
| L1 的结果 | 界面状态 | 标签 | 说明 |
|---|---|---|---|
| `online`、`same-stats`，`outside` 为真、`readable` 为假：大小和修改时间都没变 | `unconfirmed-found` | 待确认 | 找到了，确认后可用 |
| `changed`、`unverified`：只有修改时间变了，还不能读 | `unconfirmed-maybe-changed` | 可能已变化 | 可能已变化，确认后核对 |

其余映射：`online` 显示为在线，不出标签；`changed` 的 `size`、`content`、`not-media` 显示为“已变化”；`missing` 显示为“缺失”，按原因给出说明（`not-found`、`no-access`、`not-downloaded`、`other-platform`、`not-a-file`）。完整的映射表在 `tests/project-file-ui-media.test.ts`。

## 不适用的状态
- `MediaStatusBadge`、`MediaStatusNote` 没有自己的加载中和出错：“核对中”“无法核对”就是它们显示的两种状态（12-04-badges 里的 scene-g、scene-h）。“空”是文件在线，不渲染（12-04-none）。
- `MediaAttentionBanner` 的“空”是没有要处理的素材，不渲染（12-04-none）。
