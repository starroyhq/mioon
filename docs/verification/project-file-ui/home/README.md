# 第 1 组：首页、新建项目、打不开

组件：
- `RecentProjectsView`、`RecentProjectCard`、`ProjectInboxNotice`（`RecentProjects.tsx`）：12-01；
- `NewProjectFileDialog`：12-02；
- `ProjectOpenFailureDialog`：12-03、12-03b、12-03c、12-03d，以及只读位置。

几处共同的差异，表里不再逐行写：
- 截图里没有应用的顶栏（Mioon、搜索、打开…、新建项目），它属于现有首页。整页截图的内容因此比预览靠上。
- 12-02、12-03 的对话框背后是 U1 的首页组件，不是整个应用。遮罩用共用对话框自带的暗化和模糊，比预览模糊。
- 对话框打开时会聚焦第一个控件。12-02 聚焦名称输入框，和预览一样带白框；其余对话框聚焦的是按钮，截图前在标题上点一下鼠标，所以和用鼠标打开时一样不显示焦点框。
- 封面是生成的 SVG。256 色压缩以后，渐变有色带。
- 工作台的等宽字体是 JetBrains Mono，这台 Mac 上没有装，截图里路径、时长和尺寸用的是浏览器自带的等宽字体，字形和预览不同。

## 不适用的状态
- `ProjectOpenFailureDialog` 没有“空”和“加载中”：调用方拿到打开失败的结果才打开它。按钮的“进行中”和“失败”代替了这两种状态，见 12-03-locating、12-03-error、12-03d-restoring。
- `NewProjectFileDialog` 没有“加载中”：表单的值和保存位置都由调用方给出。“空”是名称为空。
- `ProjectInboxNotice` 没有自己的加载中和出错：它和最近项目由同一次读取给出，空列表时不渲染（12-01-inbox-none）。
