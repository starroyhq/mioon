# 当前整片浮点混音与固定增益候选

状态：实现、Linux 生产包原生验证与父级独立 typecheck／最终全量门均已通过。本片仍是只读候选，不含应用／undo。基线 `b9e7d1e57a687010407ae284cb55c0d4eed23abb`。上一片的已导出成片响度测量与历史验收仍见 [EXPORT-LOUDNESS.md](EXPORT-LOUDNESS.md)。本页不把历史通过数字当成本片结果。

## 本片边界

`timeline.loudness.prepare` 是显式触发的本机资源密集只读观察。它冻结当前已保存的完整时间线，实际渲染和测量完整原始 float 混音，再按用户明确填写的目标计算一个固定倍率；当全部参与片段的候选 gain 都落在现有 0–2 范围内时，实际重新渲染各片段候选并再次完整测量。

- 固定 `mixProfile: timeline-float-mix-v1`、`measurementProfile: bs1770-5-48k-stereo-fir4x-v1`，阶段为 `preencode_float_mix`。
- 目标必须显式提供，允许 −60 至 −5 LUFS、−20 至 0 dBTP；没有默认平台“标准”或自动目标。
- 完整半开范围 `[0, durationFrames)`，30 fps、48 kHz 双声道；每次必须恰好 `durationFrames × 1600` 个 sample frames。这里不能套用 AAC 编码尾部的容差。
- 保持原分段、输入 seek/resample/pad、片段局部 fade、gain/mute、amix 顺序。隐藏视频的未静音音轨仍参与；静音轨、零 gain、无音轨素材不改变。
- 候选给同一全局倍率，保持素材之间的相对音量；不是逐片段响度匹配。任一新 gain 超过 2 时整体无候选，不截断、不偷偷降低目标。
- 无有效门控响度、数字静音或过短材料明确没有候选。候选测量没有成功完成时不返回伪数值。
- 目标比较容差 0.1 LU、真峰值比较额外预留 0.5 dB 均为本应用的建议规则，不是新的平台标准或编码安全保证。
- **所有报告始终 `applyAllowed: false`**。本片没有修改 gain、统一响度、limiter、normalize、导出模式切换或自动提交。候选达标也不授予编辑权限。

## 身份与资源

请求只含项目 ID、期望 revision、固定 profiles 和显式 target，不接受路径、URL、filter、媒体字节或写入 requestId。服务验证当前真实 timeline/source graph、SQL 归属、文件身份与前后两遍实际 SHA-256；未静音且 gain > 0 的非图片来源即使记录为无声，也需核实际音轨存在性，元数据与实际字节不一致则拒绝；报告绑定 timeline ID/revision、完整区间、snapshot digest、来源资产 ID/hash/字节数、原始与候选测量、精确 gain 集合和配置。

报告仅用于当前观察展示，不是持久化候选凭据。换项目、改目标、隐藏界面、修改时间线／来源或重启均不自动再次测量。后续应用必须从服务端当前数据重新验证，不能信任客户端建议数组。

固定上限：

- 每个及全部唯一潜在可听来源合计 512 MiB；两遍 hash 合计 1 GiB。
- 完整输出最多 600 秒／18,000 帧、12 轨、100 片段、200 个原全局分段。
- 原始和候选两遍混音 PCM 合计 460,800,000 bytes；不保留整片 PCM。
- 两遍来源解码工作合计 72,000 帧，包含每个输入／原分段重复解码和一帧 lookahead。
- 全操作预算 120 秒，client 默认 125 秒，最终报告最多 64 KiB。
- 与成片样本峰值和响度观察共用单活跃准入，无队列。本次观察内部一次只有一个解码子进程；不把此限制宣称为整个应用其他导出／试听任务的全局停机。

这些是拒绝上限，不保证任何符合容量的材料都能在 120 秒内完成。超时、取消、损坏、归属变化与未确认子进程退出不产生完成报告；精确 child 退休前不释放资源所有权。JS 流式缓冲界限不等于 FFmpeg 整个进程 RSS 上限，二者验收分列。

恢复隔离工作区在输入解析／媒体访问前拒绝；普通 Web、CLI、MCP 都复用同一服务。内置 Agent 工具不扩大。既有声音试听仍是 20 秒窗口，本片不扩大试听范围。

## 与导出的关系

纯音频滤镜描述被抽为 TS 共用函数，旧导出的过滤器字符串、argv 与运算顺序是硬兼容门。原默认 v1 仍可能在中间 s16 混音发生饱和；本片浮点候选不证明默认 v1 导出已达目标。即使后续明确选择 float-v2，实际 AAC 文件仍需重新测量；预编码 TP 余量不保证编码后峰值／true peak 安全。

计量沿用上一片固定 K-weight／连续门控／4× FIR 算法与官方来源：[ITU-R BS.1770-5](https://www.itu.int/dms_pubrec/itu-r/rec/bs/R-REC-BS.1770-5-202311-I!!PDF-E.pdf)、[EBU Tech 3341](https://tech.ebu.ch/docs/tech/tech3341.pdf)、[FFmpeg ebur128](https://ffmpeg.org/ffmpeg-filters.html#ebur128)。本片不调用可能动态切换的 loudnorm；没有完整仪表认证声明。
