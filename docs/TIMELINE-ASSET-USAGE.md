# 素材在当前时间线中的使用位置

基线 `7777d2050f2853b6683231fd83a991e3d3ed71bf`。本片增加素材库的当前时间线使用次数、逐片段定位及“未用于本时间线”筛选。它是已保存快照的只读派生，不是整个项目的孤立素材扫描，也不提供删除建议。

## 用户路径

- 素材卡显示当前已保存时间线中的片段数量。隐藏或静音轨道中的片段也计入；画板、镜头参考、主体关联、历史版本和未保存表单不计入。
- 点击次数展开人类可读的片段/轨道名称及起始帧，再明确选择一个位置。多个使用位置不会自动挑第一个。
- 定位沿用未保存修改确认，进入剪辑、选中该片段和其起始帧，并展开既有时间线与右侧属性。只改变视图偏好，不执行时间线编辑。
- “未用于本时间线”与类型、搜索、收藏/拒选筛选组合；当前源素材即使不在结果中，也继续保留选择和未保存范围，并可用原“显示全部”重置。使用筛选仅在当前页面会话中保留，项目作用域改变后复位。
- 未载入、离线、存在待确认时间线操作、缺失引用或数据不一致时显示未知，未知素材仍出现在该筛选中，绝不算作零次。界面标注读取到的已保存 revision；没有声称另一个进程此刻未再更新它。

## 身份与导航安全

新 TS 投影检查所需项目/素材/时间线/轨道/片段归属、重复 ID、整数时段及完整引用。沿用当前12轨/100片段/18000帧结构边界；素材列表本身是现有 project.get 已载入集合，处理成本与其长度线性相关，没有引入截断或额外全库查询。投影不是第二套媒体解码或完整导出规则校验器。

每个目的地复制固定 project/timeline/revision/asset/clip/track、显示名称、帧位置和有界来源身份。来源身份只含相关元数据与可选字段的存在性，不含文件路径、媒体字节或认证数据。同 revision 下来源或目的地元数据不一致也会拒绝迟到选择。相同内容的后台刷新保留语义相同对象，不会每2.5秒收起列表；真实变化重新要求用户选择。

确认前、实际放弃草稿前及确认后都复核项目 epoch、导航/面板意图、工作区来源、最新选定目标及当前行的可见生命周期。切换项目、筛选隐藏、收起或卸载、另一次选择、删除/替换片段都会让旧回调失效。定位后延迟滚动仅作用于当前选中的时间线 DOM，不拼接来自名称的选择器。

现有片段草稿 discard 仅增加可选同步条件：等待在途 autosave 后再次核对，DELETE 前条件必须仍成立，ACK 后不得清除失效目标的表单。旧调用默认语义不变。合法时已发出的 DELETE 不能撤销；若其后目标变化，精确删除确认仍可记录，但保留当前未保存输入，不继续导航。未知 PUT 仍不允许清除身份或盲目重提。

## 兼容与边界

无新数据库迁移、旁文件、RPC/CLI/MCP目录、Agent工具、生成或付费权限。外部客户端继续读取原已保存时间线；本片不创造另一套修改服务。原媒体、历史快照、回执和渲染参数不随定位改变。恢复工作区沿用既有本地查看/编辑和视图偏好规则，没有解除继承任务限制。

新增逻辑为 TS/TSX，旧 App/AssetLibrary 仅接线。TaskCenter 原抽屉位置、说明密度和其他表单恢复范围不属于本片。
