# Timeline basics · 时间线入门

这是一个由原创程序化图形和音调组成的 10 秒竖屏项目。

- 输出：1080 × 1920，30 fps，共 300 帧。
- Video 1：First light 在 0–4 秒；After hours 在 5–10 秒。中间故意留出 1 秒空隙。
- Video 2：透明星形卡片在 2–7 秒叠加，展示画中画。
- Audio 1：音调在 0–4 秒和 5–9 秒播放；第二段从源音频第 5 秒开始。

通过 Mioon 的受控模板实例化操作使用本示例（timeline-basics，版本 1）。它会建立新的项目身份，并复制四份素材。本目录不是用户工作区或备份，不附带本机 history、Mio 对话、任务、撤销、cache、凭据或信任记录。

所有素材都以项目内相对路径引用。实例建立后，即使安装目录中的模板被移走，也可以离线重开和读取素材。应用首次打开实例时正常创建属于它的空本机记录。

来源和重建方法见 SOURCE.md，项目许可见 LICENSE；逐文件大小和 SHA-256 见 manifest.json。
