# Mioon 界面改版实施计划（完整版）

依据：`designs/mioon-design.pen`（最终设计稿，预览 `designs/mioon-design.png`）与 `designs/DESIGN-GUIDE.md`（规范）。
设计稿是目标方案：功能、尺寸、布局、组件样式以设计为准，代码向设计靠拢；与设计冲突的旧测试、旧文档按新设计更新。

第 3 节的 6 项产品决策已全部确认实施。

## 1. 目标与范围

**界面**：把 Web / Electron 渲染层改为设计稿：黑白灰 + 白色主题色、重新设计的组件、精简顶栏、按模式区分的右侧面板、分步导出弹窗、任务浮层与任务弹窗、设置中心、新的项目首页，以及 1050×680 最小窗口适配。

**业务**：取消生成次数上限、时间线输出改为 1080p、智能助理按目标一次性授权、新增外观偏好、项目首页信息、波纹删除。

**涉及代码**

- `packages/ui`：设计 token、通用组件。
- `apps/web/src`：工作台全部界面。
- `packages/i18n`：四种语言（简中、繁中、English、日本語）文案。
- `packages/contracts`、`packages/business`、`apps/server`、`apps/cli`、`apps/mcp`：第 3 节决策涉及的协议、业务、持久化与传输。
- `tests/`、`docs/`、`skills/mioon/`：同步更新。

**不在范围**：新增或升级依赖、打包签名发布、真实供应商调用、自动迁移用户已有数据目录（迁移只在后端按 schema 规则进行）。

## 3. 已确认的产品决策

### D1 · 取消生成次数上限

- 删除 `*_MAX_GENERATIONS` 环境变量的读取、校验、“缺失配置”判定与按已用次数拦截；`MIOON_ENABLE_LIVE_PROVIDER` 总开关、密钥、`*_OUTPUT_HOSTS`、`*_APPROVED_ASSET_SHA256`、区域配置保持不变。
- 仍保留：真实生成默认关闭、未知结果先对账不自动重发、每次提交保留原始 requestId。
- 能力查询（`provider list`）不再返回次数相关字段或缺失项；保持字段删除对旧客户端无害（旧字段直接不出现，不改其他字段语义）。
- 图像生成（OpenAI 固定预设 / 自定义 Images）若有类似计数，按同一原则处理；逐次付费确认属于“确认”而非“次数上限”，保留。
- 更新 README“五个平台的生成配置”、`docs/PROVIDERS.md`、`docs/PROVIDER-TRIAL-READINESS.zh-CN.md`、`docs/LIVE-VERIFICATION-APPROVAL.zh-CN.md`、`skills/mioon` 中的相关描述，以及引用 `MAX_GENERATIONS` 的测试夹具（`tests/*-transports.test.mjs`、`cli-v4.test.mjs`、`browser_*.py` 等）。

### D2 · 时间线输出改为 1080p

- 新预设：`portrait_1080`（1080×1920）、`landscape_1080`（1920×1080）、`square_1080`（1080×1080），30fps；新项目默认 `portrait_1080`。
- 旧的 `*_720` 预设保留为可读的旧规格：已有项目、历史渲染、导出记录、备份恢复照常可用，不自动改写。旧项目在属性 / 导出中显示其真实规格；是否提供“升级到 1080”由空白时间线规则决定（与现在“仅初始空白时间线可切换格式”一致）。
- 合成器按项目规格原生渲染；预览分辨率可低于输出（保持预览速度），在界面上标明。
- 导出尺寸选项改为“原始尺寸 / 短边 720 / 短边 360”，原生 1080 项目不再“放大”；旧 720 项目保留原选项含“放大到 1080”的说明。
- 涉及：`packages/contracts/src/timeline-format.mjs`、`timeline-export-float.ts`、`export-preflight.mjs`、`index.mjs` 操作说明；`packages/business/src/timeline-inputs.mjs`、`timeline-media.mjs`、`timeline-export-capabilities.mjs`、`timeline-export-range-plan.ts`、预览 / 样片 / 抽帧 / 字幕烧录 / LUT / 不透明度等所有按 720 假设的路径；HTTP / CLI / MCP schema 与文档 `docs/TIMELINE-OUTPUT-FORMATS.md`、`docs/EXPORT-SETTINGS.md`。
- 分镜顺序导出（`720×1280` 固定）同步改为项目规格或 1080×1920，并更新说明。
- 需要 schema 迁移时按现有 `workspace-schema-v*.ts` 规则新增版本，并补齐备份 / 恢复兼容测试。

### D3 · 智能助理按目标一次性授权

- 授权单位：目标地址 + 模型 + 发送范围类别（如“时间线 + 选中片段”）。首次发送弹出确认（发送范围、目标地址与模型、可能计费），确认后持久保存于本机工作区，后续同一单位不再询问。
- 目标地址、模型或范围类别任一变化都要重新确认；设置中心“智能助理”页列出已授权目标，可逐条撤销。
- 每次发送仍在输入框上方显示“发送目标 · 范围”标签，可点开查看发送内容。
- 后端保存授权记录并在发送时校验，不只依赖前端状态；现有“未确认不发送、未知结果不重发”的保护保持不变。
- 涉及：`apps/web/src/agent-chat.js` 授权键逻辑、Agent 设置与发送服务（`packages/business` 中 agent 相关模块）、契约与 HTTP / MCP、`docs/AGENT-CHAT.md` 等。

### D4 · 设置中心新增项

- 通用 · 外观：主题（深色 / 跟随系统）、界面缩放（90–125%）、界面密度（标准 / 紧凑：紧凑时工具栏与列表行高 24）、时间码显示（时:分:秒:帧 / 秒）、减少动态效果。保存在工作区偏好，重启后恢复。
- **浅色主题**：设计稿只有深色。实施时先按指南第 2 节推导一套浅色 token（同样满足对比度），在设置中心与一张剪辑页面上截图给用户确认后再全量启用；未确认前“跟随系统”在浅色系统下仍显示深色并在说明中注明。
- 快捷键页：列出全部快捷键（分割 ⌘B、撤销 ⌘Z、重做 ⇧⌘Z 等），首版只读。
- 关于页：版本、渠道（正式 / 开发）、数据目录、开源许可与 FFmpeg 外部依赖说明。
- 智能助理页：连接设置（迁自原 Agent 设置）+ D3 的已授权目标列表。
- 扩展页：迁入现有 Comfy / 自定义 Images 等扩展设置。
- 工作区页：数据目录、占用空间、离线备份与恢复（迁自右侧面板底部）。
- 视频工具页：FFmpeg / ffprobe 路径与能力检测（复用首次启动配置能力）。
- 设计稿未单独绘制的页（智能助理、扩展、快捷键、关于）沿用设置中心的框架与表单组件实现。

### D5 · 项目首页信息

- 卡片：封面（当前选用的首个镜头版本或时间线首帧缩略图，无则占位）、名称、画幅、镜头数、时长、更新时间、“最近打开”标记、“更多”菜单（重命名、打开所在位置、删除项目 → 危险确认）。
- 顶栏搜索（按名称），排序（最近打开 / 更新时间 / 名称），网格 / 列表切换，选择记在本机偏好。
- 新建项目弹窗：名称、“创作方向”（沿用现有项目描述字段，0–500 字）、时间线画幅（D2 三种）。
- 封面与统计优先由现有数据推导；若需要新增读取接口，走 `packages/contracts` 并同步 HTTP / CLI / MCP。

### D6 · 波纹删除

- 片段“更多”菜单增加“波纹删除”（快捷键 ⇧⌫），普通“从时间线移除”保留（⌫）。
- 波纹删除：移除片段后，同一轨道上位于其后的片段整体前移被删片段的时长；其他轨道不动（与“同轨不重叠、跨轨叠放”规则一致）。前移后不得与同轨其他片段重叠，否则拒绝并给出原因。
- 一次操作进入撤销历史，可撤销 / 重做；CLI / MCP 提供同名操作；智能助理提议的移动仍为非波纹，不受影响。
- 删除确认弹窗按类型显示不同说明：普通删除“原位置留空”；波纹删除“后续片段前移 N 帧”。
- 涉及：`packages/business/src/timeline.mjs`（新增 `timeline.clip.rippleRemove` 或给 remove 增加显式模式，二选一，推荐新增操作以免改变旧语义）、`timeline-subtitle-schema.mjs` 等操作清单、`packages/contracts`、历史与恢复、`docs/TIMELINE.md`、`docs/CONTRACT.md`。
