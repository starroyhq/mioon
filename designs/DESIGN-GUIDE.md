# Mioon 设计生成指南

供 `designs/*.pen` 统一遵循。每个 .pen 生成时都附上本文件；规范变化先改这里，再重新生成。本设计为目标方案：以产品设计合理为准，不受现有实现限制；功能、尺寸、规格与布局以本文件为准，代码按设计稿调整。

## 1. 产品与原则

Mioon 是本地优先的 AI 视频创作桌面应用（Electron，简体中文界面）。一个项目两种模式：
**画板**（构思镜头、首帧参考、生成与比较版本）和**剪辑**（多轨编排、预览、导出）。

- 专业工具气质：深色中性底，内容（画面）是主角，界面退后。参考 DaVinci Resolve、Final Cut Pro、Linear、Figma 的克制程度。
- 主题色为白色：界面整体黑白灰，白色承担主操作、选中和焦点。颜色只承担含义：语义色 = 状态，片段色 = 媒体类型。品牌标识是唯一的装饰性彩色元素。
- 信息密度适中：桌面工具可以紧凑，但每个区域只有一个主操作；技术说明默认收起（ⓘ 提示或“了解更多”），不在界面上铺大段文字。
- 状态可见：保存/草稿、预览是否过期、任务进度、离线等状态用统一的徽标与提示条表达。
- 尺寸基准 1440×900，最小窗口 1050×680。根字号 13px。文字下限 10px，点击区域下限 24px。
- 对比度：正文和按钮文字与底色对比度 ≥ 4.5:1，大字与图标 ≥ 3:1。下文色值已按此校验。
- 界面支持简体中文、繁体中文、English、日本語四种语言：文字按钮不用固定宽度，标签按英文比中文长 30–50% 预留空间，长文本省略并提供完整提示。
- 快捷键在 Tooltip 中显示（如“分割  ⌘B”）。

## 2. 色彩

### 中性灰（带极轻冷调，不是纯黑）

| Token | 值 | 用途 |
|---|---|---|
| bg-canvas | #0B0C0E | 窗口底、画布底、预览监视器底 |
| bg-panel | #141518 | 面板 |
| bg-surface | #1B1D21 | 卡片、控件底 |
| bg-raised | #23252A | 浮层、菜单、弹窗 |
| bg-hover | #2A2D33 | 悬停 |
| bg-selected | #31343B | 列表/卡片选中底 |
| bg-input | #0F1013 | 输入框（比面板更深） |
| border-subtle | #22242A | 分隔线 |
| border-default | #2E3138 | 控件描边 |
| border-strong | #3D4149 | 强调描边 |
| text-primary | #ECEDEF | 主文字 |
| text-secondary | #A3A7AF | 次要文字 |
| text-tertiary | #7D828C | 辅助、占位 |
| text-disabled | #4A4E56 | 禁用 |

### 主题色：白

| Token | 值 | 用途 |
|---|---|---|
| accent | #F2F3F5 | 主按钮填充、选中 Chip 填充 |
| accent-hover | #FFFFFF | 主按钮悬停 |
| accent-pressed | #D4D6DA | 主按钮按下 |
| accent-foreground | #0B0C0E | 主按钮、选中 Chip 上的文字 |
| accent-line | #FFFFFF | 选中描边、页签下划线、焦点环、播放头 |
| accent-subtle | rgba(255,255,255,0.10) | 选中底、焦点光晕 |

白色与主文字接近，所以“选中”不能只靠文字变白，必须同时有底色（bg-selected / accent-subtle）或描边（accent-line）。主题色只用于：主按钮、选中/焦点、播放头、进行中进度、链接（链接另加下划线）。不用于大面积背景。

### 语义色

| 含义 | 前景 | 底色（约 14% 透明） | 用途 |
|---|---|---|---|
| danger | 文字/图标 #F26464，实心填充 #D63A3A（白字 4.6:1） | rgba(240,74,74,0.14) | 删除、移除、失败、不可恢复操作 |
| warning | #F2A93B | rgba(242,169,59,0.14) | 预览过期、未保存、需确认 |
| success | #3DBE7A | rgba(61,190,122,0.14) | 完成、已保存、已连接 |
| info | text-secondary + border-default（中性） | bg-surface | 一般说明 |

- 删除类按钮一律 danger；危险确认弹窗的确认按钮为实心 danger。
- “进行中”（渲染、生成、导出）用白色进度条，不另设颜色。
- 语义色只出现在提示、徽标、状态点、输入错误和危险操作上；时间线上片段只用片段色，片段出错时叠加 danger 描边与图标。

### 媒体 / 片段色（低饱和深底 + 亮边，片段上文字 ≥ 9:1）

| 类型 | 填充 | 边/图标/波形 |
|---|---|---|
| 视频 | #1E3A5F | #5B9BE6 |
| 图片 | #1F4A45 | #4FC1B0 |
| 音频 | #24452C | #5FC27A |
| 字幕 | #33295C | #9C8CFF |

- 生成的镜头版本本质是视频，沿用视频色。
- 片段色同样用于素材卡类型角标、素材库类型筛选、画板节点类型图标。
- 音频绿与 success 绿只在不同场景出现（时间线/素材 vs 提示/徽标），不会同屏混淆。
- 选中片段：2px accent-line 描边 + 两侧白色修剪手柄；禁用轨道：50% 不透明度；播放头：白色竖线 + 顶部倒三角。

### 品牌与细节约定

- 品牌标识暂用文字字标“Mioon”：Noto Sans SC 15px，字重 600，颜色 text-primary（#ECEDEF）；正式 Logo 定稿后替换。
- 进行中任务的图标：bg-surface 底 + text-primary 图标；失败用 danger，排队用 text-secondary。
- 播放头经过刻度尺时，被遮挡的刻度文字隐藏（刻度线保留），不做位移。

## 3. 字体与字号

- 界面：PingFang SC / Noto Sans SC（设计稿按 Noto Sans SC 渲染）；数字、时间码、帧数：JetBrains Mono（等宽、tabular）。
- 字号阶梯（px / 字重 / 行高）：Display 24/600/1.3，Title 18/600/1.4，Section 14/600/1.4，Body 13/400/1.5，Label 12/500/1.4，Caption 11/400/1.4，Mono 12/500，Mono-lg 20/600（预览时间码）。

## 4. 尺寸、间距、圆角、层级

- 间距以 4 为单位：4 / 8 / 12 / 16 / 20 / 24 / 32。面板内边距 12，控件间距 8，分组间距 20。
- 控件高：默认 28，紧凑 24（工具栏、轨道头、列表行内操作），大 36（空状态、弹窗主操作）。输入框同为 28。
- 顶栏 44；面板标题栏 36；底部固定操作栏 48。
- 面板：素材库宽 260（可收成 44 宽图标栏），属性面板宽 320，时间线默认高 300（最小 160，可收起为 40 高工具栏）。面板之间 6px 间隙，面板圆角 10。
- 时间线：轨道头宽 168，刻度尺高 24，视频/图片轨高 52（片段内显示缩略帧），音频轨高 44（波形），字幕轨高 32。
- 画板镜头节点宽 240；素材网格在 260 宽面板中两列。
- 弹窗：确认 420 宽，标准 560 宽，大型（导出、设置、版本对比）960×640。
- 圆角：控件 6，卡片 8，面板 10，弹窗 12，徽标/开关 全圆。
- 层级：canvas → panel → surface → raised；浮层用 bg-raised + border-default + 柔和阴影（0 8 24 rgba(0,0,0,.45)），不用粗边框。

## 5. 组件规范（重新设计，不沿用现有样式）

- **按钮**：变体 primary（白底黑字）、secondary（bg-surface + border-default + 白字）、ghost（透明，悬停 bg-hover）、danger（#D63A3A 实心白字）、danger-ghost（#F26464 文字）、icon（方形，24/28）。状态：默认、悬停、按下、焦点（1.5px 白色描边 + accent-subtle 光晕）、禁用、加载中（旋转图标）。图标统一 16px 线性图标，描边 1.5。
- **分段控件**：模式切换（画板/剪辑）、源/成片切换。容器 bg-input，选中段 bg-raised + 白字 + 轻阴影。
- **页签**：面板页签为下划线式（选中白字 + 2px 白下划线，未选 text-secondary）；筛选用 Chip（未选 bg-surface，选中白底黑字）。
- **输入**：bg-input + border-default，聚焦白色描边；变体：文本、多行、搜索、下拉、数字（单位后缀“帧”）、时间码（等宽）、滑块、开关（开为白色）、复选、单选。错误态 danger 描边 + 下方说明。
- **徽标**：中性、四种语义；带点徽标表示状态（已保存 success、草稿 warning、过期 warning、离线 中性）；版本徽标 V1/V2；轨道徽标 V1/A1/T（用对应片段色）。
- **素材卡**：网格卡（16:9 缩略图、左上类型角标用片段色、右下时长、文件名一行；收藏/拒选为右上小图标；悬停浮出“加入画板 / 加入时间线 / 更多”）和列表行两种；选中 2px 白描边。已用于时间线的素材显示小计数。
- **镜头节点（画板）**：编号 + 名称、画面缩略图/视频、比例时长、版本数、状态（待生成 / 生成中进度 / 已完成 / 失败 danger），首帧参考输入端口；连线：白色实线 = 首帧参考（参与生成），灰色虚线 = 视觉连线。视频播放用自定义精简控件，不用浏览器原生控件。
- **版本卡**：缩略图、V 编号、模型与时长、“当前选用”标记、操作：选用 / 比较 / 加入时间线。
- **提示**：行内提示条（warning / danger / success / info，左侧图标，右侧可带操作按钮）、Toast（顶栏下方右侧堆叠，不遮挡预览画面和时间线，可带“撤销”）、空状态（图标 + 标题 + 一句说明 + 主按钮）、ⓘ Tooltip。
- **面板**：标题栏（图标 + 标题 + 计数 + 收起按钮），内容可滚动，底部固定操作栏（左侧草稿状态徽标，右侧 放弃 + 保存）。属性面板内用可折叠分组，分组标题 Section 字号 + 展开箭头。
- **浮层**：下拉菜单（含快捷键、分隔线、danger 项）、右键菜单、弹窗（标题、正文、底部按钮右对齐）、危险确认弹窗、任务浮层（任务行：类型图标、名称、进度条/状态、操作）。
- **时间线**：刻度尺、轨道头（轨道徽标 + 名称 + 显示/静音/锁定 icon 按钮）、四类片段及选中/禁用/离线素材/出错状态、播放头、吸附对齐线、单行工具栏。
- **进度**：线性进度条（白色）、环形加载、生成任务进度（百分比 + 阶段文字）。

## 6. 目标布局

### 顶栏（44 高，全局）

左：品牌标识 · 项目切换下拉（含新建、打开、视图子菜单、导出分镜）。中：画板 / 剪辑分段控件。右：状态点（本地 · 已保存 / 草稿 / 离线，悬停看详情）· 任务按钮（运行数徽标，点开任务浮层）· 帮助 ? · 设置 · 主操作（仅剪辑模式有 primary“导出”；画板模式不放主操作——生成在镜头属性里，加入时间线在版本卡上）。macOS 下交通灯位于顶栏最左侧，品牌标识右移让位。

去掉“面板”“操作”杂项菜单，原有功能去向：
- 面板开关、重置布局 → 项目菜单“视图”子菜单与快捷键
- 区域说明 → 帮助
- Agent 对话 → 右侧“智能助理”页签；Agent 连接设置 → 设置中心
- 任务 → 顶栏任务浮层，底部“查看全部任务”打开完整任务弹窗（含失败重试、未知结果对账）
- 导出记录 → 导出弹窗“导出记录”页；导出分镜 → 项目菜单
- 工作区离线备份 → 设置中心“工作区”页

### 左侧面板（两种模式一致）

顶部页签 素材 | 主体。素材页：导入按钮（主要入口，也支持拖入）、搜索框 + 筛选按钮（类型、标记、标签、是否已用于时间线合并到一个筛选浮层，已生效条件以 Chip 显示在搜索框下）、网格/列表切换、素材网格。选中素材的标签与备注在属性面板中编辑，不常驻左侧。

### 画板模式

中：无限画布（bg-canvas 点阵）。顶部居中浮动工具条：添加镜头（主）、文字、图片、视频、生成图像（打开弹窗）、图例（首帧参考 / 视觉连线说明）。左下缩放控件（缩小、比例、放大、适应）。底部浮动分镜条：按顺序排列的镜头缩略图，可拖动排序，显示总时长，可收起。新加入画板的节点自动错开摆放，不叠在中心。

右（320）：页签 属性 | 版本 | 智能助理。
- 镜头属性分组：镜头（名称、画面描述）、首帧参考（连接状态、参考图）、生成设置（服务商与模型、文生/图生、比例、时长）、主体与风格。底部固定“生成镜头”主按钮（有草稿时为“保存并生成”）。
- 版本页：版本卡列表；“比较”打开版本对比大弹窗（左右两个播放器 + 参数差异）。
- 选中图片节点：属性中提供“编辑图像”（参考图编辑）；选中素材：标签与备注。

### 剪辑模式

中：预览监视器为主体。监视器标题栏左侧为 源素材 / 成片 分段控件，右侧为输出规格（如 1080×1920 · 30fps）。过期时监视器上方出现 warning 提示条“预览已过期 · 更新预览”，渲染中显示白色进度。监视器下方播放控制条：上一帧、播放/暂停、下一帧、当前时间码（Mono-lg）/ 总时长、入点 / 出点、声音试听开关、全屏。

右（320）：页签 属性 | 智能助理。片段属性分组：基础（名称、轨道、开始帧、时长、素材入点）、画面（位置与缩放、不透明度、LUT）、音频（音量、音量包络、淡入淡出、响度分析）、来源（返回来源、替换来源）。底部固定保存栏；“从时间线移除”放在标题栏“更多”菜单里，为 danger 项。

下：时间线。单行工具栏：左侧编辑工具（选择、分割、吸附、波形显示），中间播放头时间码输入，右侧撤销 / 重做、历史、“+ 轨道”下拉（画面轨 / 音频轨 / 字幕轨）、缩放滑块。底部状态栏一行：总时长 · 片段数 · 操作提示。窗口较矮时预览不小于 240 高，时间线可收起到只剩工具栏。

### 最小窗口（1050×680）

- 顶栏精简：不显示项目名（只留品牌标识 + 下拉箭头），任务按钮只显示图标和数字，保存状态缩写为“已保存 / 草稿”。
- 左右面板可收成 44 宽图标栏；图标栏点击时面板以浮层盖在画布上，浮层右上角“固定”可改回常驻。
- 画板浮动工具条只保留“添加镜头”文字，其余工具只显示图标（Tooltip 给出名称）。
- 时间线工具栏最右侧有收起 / 展开按钮；收起后只剩 40 高工具栏。两侧面板标题栏都有收起按钮。

### 导出（大弹窗 960×640）

顶部页签：本次导出 | 导出记录。左侧试看播放器（可选 1–300 帧样片预览），右侧分步：检查（编码能力、素材）→ 设置（名称、画质或码率、尺寸、全片或选区、响度）→ 确认 → 进度 → 完成（打开文件 / 显示所在位置）。关闭弹窗不取消导出，进度同步在任务浮层。

### 智能助理

首次向某个模型发送时显示一次授权确认（发送范围、地址、可能计费），确认后输入框上方只保留一个“发送目标 · 范围”小标签，点击可查看或更改。消息区为对话气泡，修改建议以可审阅卡片呈现（应用 / 忽略）。

### 项目首页与登录

- 首页：顶栏（品牌、搜索、设置、primary“新建项目”）；项目卡片网格（封面缩略图、名称、更新时间、镜头数与时长、最近打开标记）；空状态居中引导创建。新建项目为标准弹窗（名称、创作方向可选、时间线画幅 竖屏 1080×1920 / 横屏 1920×1080 / 方形 1080×1080，统一 1080p、30fps）。没有项目时顶栏不显示“新建项目”，只保留空状态中的主按钮。
- 登录（仅浏览器入口需要，桌面版自动登录）：居中卡片，品牌、访问令牌输入、进入按钮、语言选择位于卡片右上角，一行说明“令牌在本机 data/access-token”。

### 设置中心（大弹窗 960×640）

左侧导航：通用（语言、外观）、工作区（数据目录、离线备份与恢复）、视频工具（FFmpeg / ffprobe 路径与检测）、模型与服务、智能助理、扩展、快捷键、关于。右侧为表单，底部固定保存栏。

模型与服务：密钥只在后端环境变量中配置，界面只显示变量名（Runway `RUNWAYML_API_SECRET`、Seedance `ARK_API_KEY`、Veo `GEMINI_API_KEY`、MiniMax `MINIMAX_API_KEY`、Vidu `VIDU_API_KEY`）与是否已配置。真实生成有总开关，**不设任何次数上限**（不出现每日上限、次数上限等控件或文案）。
