# 剧本拆镜头

用户给出剧本、小说段落或分场大纲，要把它拆成画板上可以生成的镜头时，按下面的顺序做。

## 先确认目标

- 先看项目概况和项目说明：画幅、每集时长、镜头数量、风格和禁忌。项目说明里写了目标时长或镜头数时照做。
- 还需要知道用哪个视频模型生成。用户在消息里说了模型就用它。
- 目标时长或模型不清楚、而且会明显改变拆法时，用 mioon_ask 问一次，选项写成具体的时长或模型，不要猜。

## 读模型允许的时长

- 每个镜头的时长必须是所用模型允许的值。先用 mioon_tools_load 加载 video 组，再调用 provider.list，找到所用模型，读它的 durations（单位秒）。
- 只能用 durations 里列出的值。不要套用其他模型的时长，也不要按经验写一个时长。
- 用户没有指定模型时，用 provider.list 里可用的模型，并在回复里说明按哪个模型的时长拆分；有多个可用模型且时长不同时，用 mioon_ask 让用户选。
- 用户换了模型，就重新读新模型的 durations，再按新的时长重新拆。

## 拆分方法

1. 先分场：地点或时间变化就是新的一场。
2. 再按节拍拆镜头：一个镜头只表达一个主要动作，或一句关键对白及其反应。
3. 时长：在允许的时长里取最接近这个节拍长度的值；节拍比最长的允许值还长，就拆成两个镜头。
4. 对白：较长的对白拆成说话人镜头和听者反应镜头，对话双方保持同一条轴线，不要越轴。
5. 每场开头可以有一个交代环境的远景或全景；动作的关键时刻用近景或特写。
6. 总时长：各镜头时长之和接近目标（误差约一成）。超出时先合并次要节拍，不足时补环境或反应镜头。

## 每个镜头写什么

- 标题：两位编号加简短内容，例如“03 林夏抬头”。
- 提示词：按“镜头提示词”方法写主体、动作、景别与运镜、场景与光线；角色外貌按项目说明和主体保持一致。
- 时长：上面读到的允许值之一。
- 画幅：用项目时间线的画幅（见项目概况）；项目说明另有要求时按说明。

## 写入画板

- 加载 canvas 组。先用 shot.inspect 看已有镜头，避免重复创建；不要删除或改写用户已有的镜头，除非用户要求。
- 用 shot.create 按顺序逐个创建。镜头较多时分批创建，每批完成后再继续。
- 创建镜头不会生成视频。生成需要用户另行要求，并按正常流程确认。

## 回复

说明拆成了几个镜头、总时长，以及按哪个模型的时长限制拆分；指出合并或拆开的地方，以及需要用户决定的问题。
