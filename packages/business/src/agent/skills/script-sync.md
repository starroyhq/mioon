# 脚本改动同步

广告文案、分镜脚本或剧本改了，或者项目说明里的角色、场景、禁忌变了，需要让画板上的镜头跟着改时使用。只改镜头的文字内容，不重新生成。

## 读取

- 项目说明已在本轮上下文里。
- 脚本通常在画板的文字节点里，用 node.inspect 分页读完。长脚本可能分在几个文字节点里（每个最多 5000 字），按画板上的位置从上到下、从左到右拼起来。节点文字较长时每页少读几个，避免结果被截断。用户在消息里贴了脚本时，以消息为准。
- 用 shot.inspect 分页读完全部镜头。提示词超过 1000 字节时只返回开头，并标为截断（promptTruncated）。
- 用户只说“改了”、没说改了哪里时，问一次改动的位置，或者请用户把改动前后的段落贴出来。

## 找出受影响的镜头

逐条比较改动和每个镜头的标题、提示词和时长：
- 人名、角色设定、服装或持物变了：提到这个角色的镜头都要改。
- 场景、时间或天气变了：这个场景里的镜头都要改。
- 台词或动作变了：对应节拍的镜头要改。节拍被删掉时不要删除镜头，标出来交给用户决定。
- 新增了节拍：列出建议新增的镜头，不要自己插进已有的顺序。
- 项目说明里的禁忌变了：违反新禁忌的镜头都要改。

## 先列出再修改

- 修改前先整理出受影响的镜头，以及每个打算怎么改。
- 超过 5 个镜头，或者不确定某个镜头该不该改时，用 mioon_ask 把这份清单交给用户确认范围，再改。
- 提示词被截断的镜头只看得到开头，不要整段改写：在回复里列出来请用户手动改，或者问用户能不能按开头部分重写整段。

## 修改

- 加载 canvas 组，对每个镜头调用 shot.update，带上 shot.inspect 读到的 expectedRevision。
- 只改受影响的句子，保留用户写的其他内容和顺序，写法按“镜头提示词”方法。
- 时长只在节拍长度明显变化时改，取所用模型 durations 里的值（见“剧本拆镜头”方法）。
- 镜头绑定了主体、而角色外貌变了时，按“角色一致性”方法处理，先问用户要不要更新主体。
- 不要提交生成。已经生成过的镜头在回复里列出来，由用户决定是否重新生成。

## 回复

列出改了哪些镜头、每个改了什么，以及没改、需要用户决定的镜头。告诉用户这一轮的修改可以用“整体撤销”一起撤回。
